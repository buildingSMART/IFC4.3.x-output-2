7.2.4.20 Pset_FlowInstrumentTypeThermometer

PSET_TYPEDRIVENOVERRIDE / IfcFlowInstrument / THERMOMETER

Flow Instrument Type Thermometer: A device that reads and displays a temperature value at a point.
: 温度を測定し表示するデバイス。
