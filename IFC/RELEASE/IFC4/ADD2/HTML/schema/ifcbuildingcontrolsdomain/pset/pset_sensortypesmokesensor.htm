7.2.4.42 Pset_SensorTypeSmokeSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / SMOKESENSOR

Sensor Type Smoke Sensor: A device that senses or detects smoke. HISTORY: PressureSensorSensorSetPoint (error in previous release) changed to SetPointConcentration. Range, accuracy and time constant deleted.
: 煙を感知または検出するデバイス。
