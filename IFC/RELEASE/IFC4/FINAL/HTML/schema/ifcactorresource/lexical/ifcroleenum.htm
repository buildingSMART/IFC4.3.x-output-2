8.1.2.2 IfcRoleEnum

This enumeration defines roles which may be played by an actor.

HISTORY  New type in IFC1.5.
IFC4 CHANGE  Spelling of COMMISSIONINGENGINEER corrected.

Enumerated Item Definitions:

  • SUPPLIER
  • MANUFACTURER
  • CONTRACTOR
  • SUBCONTRACTOR
  • ARCHITECT
  • STRUCTURALENGINEER
  • COSTENGINEER
  • CLIENT
  • BUILDINGOWNER
  • BUILDINGOPERATOR
  • MECHANICALENGINEER
  • ELECTRICALENGINEER
  • PROJECTMANAGER
  • FACILITIESMANAGER
  • CIVILENGINEER
  • COMMISSIONINGENGINEER
  • ENGINEER
  • OWNER
  • CONSULTANT
  • CONSTRUCTIONMANAGER
  • FIELDCONSTRUCTIONMANAGER
  • RESELLER
  • USERDEFINED: User defined value to be provided.
