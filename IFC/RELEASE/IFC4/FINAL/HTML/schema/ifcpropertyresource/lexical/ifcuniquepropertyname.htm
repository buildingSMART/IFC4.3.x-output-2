8.16.4.1 IfcUniquePropertyName

The function gets the set of names, used by elements in a set (e.g. by individual properties in the set of a property set. It verifies that no name appears twice.

HISTORY  New function in Release IFC2x2

EXPRESS Specification

FUNCTION IfcUniquePropertyName
(Properties : SET [1:?] OF IfcProperty)
:LOGICAL;

LOCAL
  Names : SET OF IfcIdentifier := [];
END_LOCAL;

REPEAT i:=1 TO HIINDEX(Properties);
  Names := Names + Properties[i].Name;
END_REPEAT;
RETURN (SIZEOF(Names) = SIZEOF(Properties));
END_FUNCTION;
