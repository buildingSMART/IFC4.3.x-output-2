6.4.4.3 Pset_FurnitureTypeChair

PSET_TYPEDRIVENOVERRIDE / IfcFurniture / CHAIR

A set of specific properties for furniture type chair. HISTORY: First issued in IFC Release R1.5. Renamed from Pset_Chair

buildingSMART Data Dictionary

PSD-XML

  • SeatingHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    SeatingHeight: The value of seating height if the chair height is not adjustable.
  • HighestSeatingHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    HighestSeatingHeight: The value of seating height of high level if the chair height is adjustable.
  • LowestSeatingHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    LowestSeatingHeight: The value of seating height of low level if the chair height is adjustable.
