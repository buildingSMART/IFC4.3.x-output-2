6.4.4.16 Pset_SystemFurnitureElementTypeWorkSurface

PSET_TYPEDRIVENOVERRIDE / IfcSystemFurnitureElement / WORKSURFACE

A set of specific properties for work surfaces used in workstations. HISTORY: First issued in IFC Release R1.5. Renamed from Pset_Worksurface

buildingSMART Data Dictionary

PSD-XML

  • UsePurpose
    P_SINGLEVALUE / IfcLabel
    UsePurpose: The principal purpose for which the work surface is intended to be used e.g. writing/reading, computer, meeting, printer, reference files, etc.
  • SupportType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_FurniturePanelType: FREESTANDING, SUPPORTED, OTHER, NOTKNOWN, UNSET
    SupportType: Available support types from which that required may be selected.
  • HangingHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    HangingHeight: The hanging height of the worksurface.
  • NominalThickness
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalThickness: The nominal thickness of the work surface.
  • ShapeDescription
    P_SINGLEVALUE / IfcLabel
    ShapeDescription: A description of the shape of the work surface e.g. corner square, rectangle, etc.
