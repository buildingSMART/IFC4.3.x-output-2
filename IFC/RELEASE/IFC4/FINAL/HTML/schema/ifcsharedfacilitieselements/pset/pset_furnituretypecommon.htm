6.4.4.4 Pset_FurnitureTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcFurniture

Common properties for all types of furniture such as chair, desk, table, and file cabinet. HISTORY: First issued in IFC Release R1.5. Renamed from Pset_FurnitureCommon. IFC 2x4: 'IsBuiltIn' property added

buildingSMART Data Dictionary

PSD-XML

  • Description
    P_SINGLEVALUE / IfcText
    Description: Specific description of this type of furniture.
  • Style
    P_SINGLEVALUE / IfcLabel
    Style: Description of the furniture style.
  • NominalHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalHeight: The nominal height of the furniture of this type. The size information is provided in addition to the shape representation and the geometric parameters used within. In cases of inconsistency between the geometric parameters and the size properties, provided in the attached property set, the geometric parameters take precedence.
  • NominalLength
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalLength: The nominal length of the furniture of this type. The size information is provided in addition to the shape representation and the geometric parameters used within. In cases of inconsistency between the geometric parameters and the size properties, provided in the attached property set, the geometric parameters take precedence.
  • NominalDepth
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalDepth: The nominal depth of the furniture of this type. The size information is provided in addition to the shape representation and the geometric parameters used within. In cases of inconsistency between the geometric parameters and the size properties, provided in the attached property set, the geometric parameters take precedence.
  • MainColor
    P_SINGLEVALUE / IfcLabel
    MainColor: The main color of the furniture of this type.
  • IsBuiltIn
    P_SINGLEVALUE / IfcBoolean
    IsBuiltIn: Indicates whether the furniture type is intended to be 'built in' i.e. physically attached to a building or facility (= TRUE) or not i.e. Loose and movable (= FALSE).
