6.4.4.1 Pset_Asset

PSET_TYPEDRIVENOVERRIDE / IfcAsset

An asset is a uniquely identifiable element which has a financial value and against which maintenance actions are recorded.
資産とは、維持管理活動が記録されている会計上の価値を持つ、単独に識別できる要素。
