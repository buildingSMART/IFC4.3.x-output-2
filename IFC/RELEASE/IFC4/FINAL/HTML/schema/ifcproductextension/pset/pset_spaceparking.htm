5.4.5.19 Pset_SpaceParking

PSET_TYPEDRIVENOVERRIDE / IfcSpace / PARKING

Properties common to the definition of all occurrences of IfcSpace which have an attribute value for ObjectType = 'Parking'. NOTE: Modified in IFC 2x3, properties ParkingUse and ParkingUnits added.
Définition de l'IAI : propriétés communes à la définition des instances de la classe IfcSpace lorsque la valeur de l'attribut ObjetType est "Parking". Nota : les propriétés TypeVehicule et NombreUnites ont été introduites depuis la révision 2x3.
IfcObjectのObjectType属性の値が"Parking"の場合に設定される共通プロパティ情報。

buildingSMART Data Dictionary

PSD-XML

  • ParkingUse
    P_SINGLEVALUE / IfcLabel
    ParkingUse: Identifies the type of transporation for which the parking space is designed. Values are not predefined but might include car, compact car, motorcycle, bicycle, truck, bus etc.
    AccessibleHandicape: Identifie le type de véhicule pour lequel le parking a été conçu. Les valeurs possibles (voiture, bus, motos, vélos,…) ne sont pas prédéfinies.
    駐車場の用途: どの車両種別の駐車場なのかを識別します。値はあらかじめ定められないが、自動車、小型車、オートバイ、自転車、トラック、バスなどを含んでいるかもしれません。
  • ParkingUnits
    P_SINGLEVALUE / IfcCountMeasure
    ParkingUnits: Indicates the number of transporation units of the type specified by the property ParkingUse that may be accommodated within the space. Generally, this value should default to 1 unit. However, where the parking space is for motorcycles or bicycles, provision may be made for more than one unit in the space.
    TypeVehicule: Nombre d'unités du type de véhicule spécifié dans la propriété TypeVehicule que peut contenir l'espace alloué au parking. Généralement, la valeur par défaut est 1. Elle peut être supérieure pour les deux roues.
    一区画当たりの駐車台数: 車両種別ごとの駐車台数のユニットごとの指定台数。一般に、この値は1台/1ユニットになるべきです。しかしながら、オートバイまたは自転車向けである場合、数台/1ユニット以上なるかもしれません。
  • IsAisle
    P_SINGLEVALUE / IfcBoolean
    IsAisle: Indicates that this parking zone is for accessing the parking units, i.e. an aisle (TRUE) and not a parking unit itself (FALSE)
    NombreUnites: Indique si cette zone du parking, comme une allée, est réservée à l'accès (VRAI) ou non (FAUX).
    通路か駐車スペースの判別: 駐車場の通路部分(TRUE)か駐車部部分(FALSE)かを示すフラグ。
  • IsOneWay
    P_SINGLEVALUE / IfcBoolean
    IsOneWay: Indicates whether the parking aisle is designed for oneway traffic (TRUE) or twoway traffic (FALSE). Should only be provided if the property IsAisle is set to TRUE.
    一方通行: 駐車場通路が一方通行(TRUE)か双方向(FALSE)かを示すフラグ。
    Sens unique: Indique si cette allée du parking est prévue pour être à sens unique (VRAI) ou à double sens (FAUX). A fournir seulement si la propriété "Est un accès" est égale à VRAI.
