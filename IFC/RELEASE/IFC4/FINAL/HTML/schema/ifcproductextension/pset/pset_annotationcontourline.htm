5.4.5.1 Pset_AnnotationContourLine

PSET_TYPEDRIVENOVERRIDE / IfcAnnotation / ContourLine

Specifies parameters of a standard curve that has a single, consistent measure value.
Définition de l'IAI : paramètres spécifiques à une courbe standard qui a une valeur simple et cohérente.
IfcAnnotation（注記）オブジェクトに関する標準の曲線に対する単一、同一の情報を設定するプロパティセット定義。GIS関連情報を扱う。
