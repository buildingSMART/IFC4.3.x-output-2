8.8.3.12 IfcDirectionList

The IfcDirectionList defines an ordered collection of directions. Each direction is a three-dimensional direction provided by a fixed list of three parameter values. The attribute DirectionList is a two-dimensional list, where

  • first dimension is an unbounded list representing each 3D direction;
  • second dimension is a fixed list of three list members, where [1] is the x-coordinate, [2] the y-coordinate and [3] the z-coordinate of the direction.
NOTE  The IfcDirectionList is introduced to provide a compact representation of an indexable representation of direction used as normals in tessellated items.
HISTORY  New entity in IFC2x4.
