6.2.4.18 Pset_DistributionSystemCommon

PSET_TYPEDRIVENOVERRIDE / IfcDistributionSystem

Distribution system occurrence attributes attached to an instance of IfcDistributionSystem.
搬送システムIfcDistributionSystemの関連属性。

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specific instance of a distribution system, or sub-system (e.g. 'WWS/VS1', which indicates the system to be WWS, subsystems VSI/400). The reference values depend on the local code of practice.
    参照記号: 空調システム、或いはサブシステムの参照ID（例えば、'WWS/VS1'はWWS系統のVSI/400サブ系統）。IDは当該地域技術基準より決められる。
    참조기호: 공조 시스템 혹은 서브 시스템의 참조 ID (예 : 'WWS/VS1'는 WWS 계통의 VSI/400 하위 계통). ID는 해당 지역 기술 기준보다 결정된다.
