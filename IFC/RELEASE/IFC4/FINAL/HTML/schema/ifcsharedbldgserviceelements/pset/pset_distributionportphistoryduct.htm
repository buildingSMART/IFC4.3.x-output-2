6.2.4.13 Pset_DistributionPortPHistoryDuct

PSET_PERFORMANCEDRIVEN / IfcDistributionPort / AIRCONDITIONING

Fluid flow performance history attached to an instance of IfcPerformanceHistory assigned to IfcDistributionPort. This replaces the deprecated IfcFluidFlowProperties for performance values.

buildingSMART Data Dictionary

PSD-XML

  • Temperature
    P_REFERENCEVALUE / IfcTimeSeries / IfcThermodynamicTemperatureMeasure
    Temperature: Temperature of the fluid. For air this value represents the dry bulb temperature.
  • WetBulbTemperature
    P_REFERENCEVALUE / IfcTimeSeries / IfcThermodynamicTemperatureMeasure
    WetBulbTemperature: Wet bulb temperature of the fluid; only applicable if the fluid is air.
  • VolumetricFlowRate
    P_REFERENCEVALUE / IfcTimeSeries / IfcVolumetricFlowRateMeasure
    VolumetricFlowRate: The volumetric flow rate of the fluid.
  • MassFlowRate
    P_REFERENCEVALUE / IfcTimeSeries / IfcMassFlowRateMeasure
    MassFlowRate: The mass flow rate of the fluid.
  • FlowCondition
    P_REFERENCEVALUE / IfcTimeSeries / IfcPositiveRatioMeasure
    FlowCondition: Defines the flow condition as a percentage of the cross-sectional area.
  • Velocity
    P_REFERENCEVALUE / IfcTimeSeries / IfcLinearVelocityMeasure
    Velocity: The velocity of the fluid.
  • Pressure
    P_REFERENCEVALUE / IfcTimeSeries / IfcPressureMeasure
    Pressure: The pressure of the fluid.
