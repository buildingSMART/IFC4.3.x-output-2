6.2.4.20 Pset_DistributionSystemTypeVentilation

PSET_TYPEDRIVENOVERRIDE / IfcDistributionSystem / VENTILATION

This property set is used to define the general characteristics of the duct design parameters within a system. HISTORY: New property set in IFC Release 2.0. Renamed from Pset_DuctDesignCriteria in IFC4.
ダクトシステムの一般的な特徴、パラメーターの属性。

buildingSMART Data Dictionary

PSD-XML

  • DesignName
    P_SINGLEVALUE / IfcLabel
    DesignName: A name for the design values.
    設計値名称: 設計値の名称。
    설계 값이름: 설계 값의 명칭.
  • DuctSizingMethod
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DuctSizingMethod: CONSTANTFRICTION, CONSTANTPRESSURE, STATICREGAIN, OTHER, NOTKNOWN, UNSET

    ダクト寸法の決め方: ダクト寸法を決める計算方法。
    덕트 치수 결정 방법: 덕트 치수를 결정하는 계산 방법.
  • PressureClass
    P_SINGLEVALUE / IfcPressureMeasure
    PressureClass: Nominal pressure rating of the system components. (Data type = PressureMeasure)
    圧力等級: ダクトシステム各部位の圧力等級（計測した圧力）。
    압력 등급: 덕트 시스템 각 부위의 압력 등급 (측정된 압력)
  • LeakageClass
    P_SINGLEVALUE / IfcPressureMeasure
    LeakageClass: Nominal leakage rating for the system components.
    漏れ率: ダクトシステム各部位の漏れ率。

    P_SINGLEVALUE / IfcReal
    ScrapFactor: Sheet metal scrap factor.
    廃材率: 金属板の廃材率。
    폐기물 비율: 금속판의 폐재 비율.
  • DuctSealant
    P_REFERENCEVALUE / IfcMaterialDefinition

    P_SINGLEVALUE / IfcLinearVelocityMeasure

    最大速度: ダクト或いは継ぎ手の最大設計風速。

  • AspectRatio
    P_SINGLEVALUE / IfcReal

    アスペクト比: デフォルトアスペクト比。

  • MinimumHeight

    최소 높이: 사각형, 원형 또는 타원형 덕트의 최소 높이입니다.
  • MinimumWidth
    P_SINGLEVALUE / IfcPositiveLengthMeasure

    最小幅: 矩形、円形或いは楕円形ダクトの最小幅。
    최소폭: 사각형, 원형 또는 타원형 덕트의 최소 폭.
