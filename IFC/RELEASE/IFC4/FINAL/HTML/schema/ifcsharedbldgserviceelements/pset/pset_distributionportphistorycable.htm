6.2.4.12 Pset_DistributionPortPHistoryCable

PSET_PERFORMANCEDRIVEN / IfcDistributionPort / ELECTRICAL

Log of electrical activity attached to an instance of IfcPerformanceHistory having an assigned IfcDistributionPort of type CABLE.
IfcDistributionPortオブジェクトがELECTRICAL型の際に関連するIfcPerformanceHistoryに設定される電力使用のログ。
