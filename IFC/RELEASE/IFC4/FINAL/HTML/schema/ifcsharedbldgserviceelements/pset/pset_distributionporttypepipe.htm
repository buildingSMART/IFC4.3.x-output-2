6.2.4.17 Pset_DistributionPortTypePipe

PSET_TYPEDRIVENOVERRIDE / IfcDistributionPort / CHEMICAL

Pipe port occurrence attributes attached to an instance of IfcDistributionPort.
IfcDistributionPortオブジェクトに設定される配管ポートに関する属性情報。

buildingSMART Data Dictionary

PSD-XML

  • ConnectionType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_PipeEndStyleTreatment: BRAZED, COMPRESSION, FLANGED, GROOVED, OUTSIDESLEEVE, SOLDERED, SWEDGE, THREADED, WELDED, OTHER, NONE, UNSET
    ConnectionType: The end-style treatment of the pipe port: BRAZED: Brazed. COMPRESSION: Compression. FLANGED: Flanged. GROOVED: Grooved. OUTSIDESLEEVE: Outside Sleeve. SOLDERED: Soldered. SWEDGE: Swedge. THREADED: Threaded. WELDED: Welded. OTHER: Another type of end-style has been applied. NONE: No end-style has been applied. USERDEFINED: User-defined port connection type. NOTDEFINED: Undefined port connection type.
    接続タイプ: 物理ポート接続： - Coaxial: 同軸コネクタ. - DSub: D-Subコネクタ. - Infrared:赤外線 - RJ: 登録済みジャック. - Radio: 無線 - USB: USB.
  • ConnectionSubType
    P_SINGLEVALUE / IfcLabel
    ConnectionSubType: The physical port connection subtype that further qualifies the ConnectionType.
    接続サブタイプ: 物理ポート接続のサブタイプ。接続タイプ以外の情報を設定する場合に使用。下記の値を設定： - DSub: DA15, DB25, DC37, DD50, DE9, DE15 - Radio: IEEE802.11g, IEEE802.11n - RJ: 4P4C, 6P2C, 8P8C - USB: A, B, MiniA, MiniB, MicroA, MicroB
  • NominalDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalDiameter: The nominal diameter of the pipe connection.
    呼び径: 配管の呼び径。
  • InnerDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    InnerDiameter: The actual inner diameter of the pipe.
    内径: 配管の実内径。
  • OuterDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    OuterDiameter: The actual outer diameter of the pipe.
    外径: 配管の実外径。
  • Temperature
    P_BOUNDEDVALUE / IfcThermodynamicTemperatureMeasure
    Temperature: Temperature of the fluid.
    温度: 流体の温度。
  • VolumetricFlowRate
    P_BOUNDEDVALUE / IfcVolumetricFlowRateMeasure
    VolumetricFlowRate: The volumetric flow rate of the fluid.
    体積流量: 流体の体積流量。
  • MassFlowRate
    P_BOUNDEDVALUE / IfcMassFlowRateMeasure
    MassFlowRate: The mass flow rate of the fluid.
    質量流量: 流体の質量流量。
  • FlowCondition
    P_BOUNDEDVALUE / IfcPositiveRatioMeasure
    FlowCondition: Defines the flow condition as a percentage of the cross-sectional area.
    流動状態: 断面の充満率で流動状態を定義する。
  • Velocity
    P_BOUNDEDVALUE / IfcLinearVelocityMeasure
    Velocity: The velocity of the fluid.
    速度: 流体の速度。
  • Pressure
    P_BOUNDEDVALUE / IfcPressureMeasure
    Pressure: The pressure of the fluid.
    圧力: 流体の圧力。
