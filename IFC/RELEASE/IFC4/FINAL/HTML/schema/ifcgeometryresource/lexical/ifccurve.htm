8.9.3.22 IfcCurve

Courbe
Kurve

An IfcCurve is a curve in two-dimensional or three-dimensional space. It includes definitions for bounded and unbounded curves.

NOTE  Definition according to ISO 10303-42:
A curve can be envisioned as the path of a point moving in its coordinate space.
NOTE Entity adapted from curve defined in ISO 10303-42
HISTORY  New entity in IFC1.0

Informal Propositions:

  1. A curve shall be arcwise connected
  2. A curve shall have an arc length greater than zero.

EXPRESS Specification:

ENTITY IfcCurve
ABSTRACT SUPERTYPE OF(ONEOF(IfcBoundedCurve, IfcConic, IfcLine, IfcOffsetCurve2D, IfcOffsetCurve3D, IfcPcurve))
SUBTYPE OF IfcGeometricRepresentationItem;
DERIVE
Dim : IfcDimensionCount := IfcCurveDim(SELF);
END_ENTITY;

 EXPRESS-G diagram

Attribute Definitions:

Dim : The space dimensionality of this abstract class, defined differently for all subtypes, i.e. for IfcLine, IfcConic and IfcBoundedCurve.
