8.9.3.17 IfcCircle

Cercle
Kreis

An IfcCircle is a curve consisting of a set of points having equal distance from the center.

NOTE  A circular arc segment is defined by using the IfcTrimmedCurve with BasisCurve being an IfcCircle.
