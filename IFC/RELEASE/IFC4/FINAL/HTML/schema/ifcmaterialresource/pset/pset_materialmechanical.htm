8.10.5.7 Pset_MaterialMechanical

PSET_TYPEDRIVENOVERRIDE / IfcMaterial

A set of mechanical material properties normally used for structural analysis purpose. It contains all properties which are independent of the actual material type.

buildingSMART Data Dictionary

PSD-XML

  • DynamicViscosity
    P_SINGLEVALUE / IfcDynamicViscosityMeasure
    DynamicViscosity: A measure of the viscous resistance of the material.
  • YoungModulus
    P_SINGLEVALUE / IfcModulusOfElasticityMeasure
    YoungModulus: A measure of the Young's modulus of elasticity of the material.
  • ShearModulus
    P_SINGLEVALUE / IfcModulusOfElasticityMeasure
    ShearModulus: A measure of the shear modulus of elasticity of the material.
  • PoissonRatio
    P_SINGLEVALUE / IfcPositiveRatioMeasure
    PoissonRatio: A measure of the lateral deformations in the elastic range.
  • ThermalExpansionCoefficient
    P_SINGLEVALUE / IfcThermalExpansionCoefficientMeasure
    ThermalExpansionCoefficient: A measure of the expansion coefficient for warming up the material about one Kelvin.
