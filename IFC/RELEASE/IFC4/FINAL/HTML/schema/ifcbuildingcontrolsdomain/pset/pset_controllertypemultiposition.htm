7.2.4.13 Pset_ControllerTypeMultiPosition

PSET_TYPEDRIVENOVERRIDE / IfcController / MULTIPOSITION

Properties for discrete inputs, outputs, and values within a programmable logic controller. HISTORY: New in IFC4, replaces Pset_MultiStateInput and Pset_MultiStateOutput.

buildingSMART Data Dictionary

PSD-XML

  • ControlType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_ControllerMultiPositionType: INPUT, OUTPUT, VARIABLE, OTHER, NOTKNOWN, UNSET
    ControlType: The type of signal modification effected and applicable ports: INPUT: Controller element is a dedicated input. OUTPUT: Controller element is a dedicated output. VARIABLE: Controller element is an in-memory variable.
  • Labels
    P_TABLEVALUE / IfcInteger / IfcLabel
    Labels: Table mapping values to labels, where each entry corresponds to an integer within the ValueRange.
  • Range
    P_BOUNDEDVALUE / IfcInteger
    Range: The physical range of values supported by the device.
  • Value
    P_BOUNDEDVALUE / IfcInteger
    Value: The expected range and default value. The LowerLimitValue and UpperLimitValue must fall within the physical Range.
