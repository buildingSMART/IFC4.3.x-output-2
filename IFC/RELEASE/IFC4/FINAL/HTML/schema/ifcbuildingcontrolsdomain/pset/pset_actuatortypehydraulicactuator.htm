7.2.4.4 Pset_ActuatorTypeHydraulicActuator

PSET_TYPEDRIVENOVERRIDE / IfcActuator / HYDRAULICACTUATOR

A device that hydraulically actuates a control element.
制御要素を水圧（油圧）で作動させるデバイス。

buildingSMART Data Dictionary

PSD-XML

    P_SINGLEVALUE / IfcPressureMeasure

    入力圧力: アクチュエータへの最大設計圧力。
    입력 압력: 액츄에이터의 최대 설계 압력
  • InputFlowrate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    InputFlowrate: Maximum hydraulic flowrate requirement.
    入力流量: 最大流量。
    입력 유량: 최대 유량
