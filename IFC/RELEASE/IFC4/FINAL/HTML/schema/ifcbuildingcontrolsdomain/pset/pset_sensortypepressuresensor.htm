7.2.4.36 Pset_SensorTypePressureSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / PRESSURESENSOR

A device that senses or detects pressure. HISTORY: PressureSensorSensorSetPoint changed to SetPointPressure. Range, accuracy and time constant deleted.
圧力を感知または検出するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • SetPointPressure
    P_BOUNDEDVALUE / IfcPressureMeasure
    SetPointPressure: The pressure value to be sensed. Use IfcPropertyBoundedValue.SetPointValue to set the set point value.
    圧力設定値: 感知される圧力。 セットポイント値を置くために、IfcPropertyBoundedValue.SetPointValueを使用する。
    압력 설정: 감지되는 압력. 세트 포인트 값을 넣으려면, IfcPropertyBoundedValue.SetPointValue를 사용하십시오.
  • IsSwitch
    P_SINGLEVALUE / IfcBoolean
    IsSwitch: Identifies if the sensor also functions as a switch at the set point (=TRUE) or not (= FALSE).
    スイッチ機能の有無: センサーが設定値でスイッチとして機能する（TRUE)か、否か（FALSE)を識別する。
    스위치 기능의 유무: 센서 설정에서 스위치 역할 (TRUE) 또는 여부 (FALSE)를 확인한다.
