7.2.4.20 Pset_FlowInstrumentTypeThermometer

PSET_TYPEDRIVENOVERRIDE / IfcFlowInstrument / THERMOMETER

A device that reads and displays a temperature value at a point.
温度を測定し表示するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • ThermometerType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_ThermometerType: DIAL, DIGITAL, STEM, OTHER, NOTKNOWN, UNSET
    ThermometerType: Identifies the means by which temperature is displayed.
    温度計タイプ: 温度が表示される手段を識別する。
    온도계 유형: 온도가 표시되는 방법을 확인한다.
  • DisplaySize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    DisplaySize: The physical size of the display. In the case of a stem thermometer, this will be the length of the stem. For a dial thermometer, it will be the diameter of the dial.
    表示サイズ: 表示のサイズ。 棒温度計の場合では、軸の長さになる。 ダイヤル温度計に関しては、ダイヤルの直径になる。
    디스플레이 크기: 표시의 크기입니다. 막대 온도계의 경우, 축의 길이가된다. 다이얼 온도계에 대해서는 다이얼 직경된다.
