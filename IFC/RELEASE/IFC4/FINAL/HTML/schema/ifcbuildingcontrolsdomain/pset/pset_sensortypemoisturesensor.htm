7.2.4.33 Pset_SensorTypeMoistureSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / MOISTURESENSOR

A device that senses or detects moisture. HISTORY: Added in IFC4.
水分を感知または検出するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • SetPointMoisture
    P_BOUNDEDVALUE / IfcPositiveRatioMeasure
