7.2.4.19 Pset_FlowInstrumentTypePressureGauge

PSET_TYPEDRIVENOVERRIDE / IfcFlowInstrument / PRESSUREGAUGE

A device that reads and displays a pressure value at a point or the pressure difference between two points.
その位置の圧力、または、2か所の差圧を測定し表示するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • PressureGaugeType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_PressureGaugeType: DIAL, DIGITAL, MANOMETER, OTHER, NOTKNOWN, UNSET
    PressureGaugeType: Identifies the means by which pressure is displayed.
    圧力計タイプ: 圧力が表示される手段を識別する。
    압력계 유형: 압력이 표시되는 방법을 확인한다.
  • DisplaySize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    DisplaySize: The physical size of the display. For a dial pressure gauge it will be the diameter of the dial.
    表示サイズ: 表示のサイズ。 ダイヤル圧力計に関しては、ダイヤルの直径になる。
    디스플레이 크기: 표시의 크기입니다. 다이얼 게이지에 관해서는 전화 직경된다.
