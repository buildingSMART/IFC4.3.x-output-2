7.2.4.30 Pset_SensorTypeIonConcentrationSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / IONCONCENTRATIONSENSOR

A device that senses or detects ion concentration such as water hardness. HISTORY: Added in IFC4.
水の硬度などのイオン濃度を感知または検出する装置

buildingSMART Data Dictionary

PSD-XML

  • SubstanceDetected
    P_SINGLEVALUE / IfcLabel
    SubstanceDetected: Identification of the substance that is being detected according to chemical formula. For example, calcium carbonate is 'CaCO3'
    対象物質: 検出されている物質の識別。
    대상 물질: 검출되는 물질의 식별.
  • SetPointConcentration
    P_BOUNDEDVALUE / IfcIonConcentrationMeasure
    SetPointConcentration: The ion concentration value to be sensed. Use IfcPropertyBoundedValue.SetPointValue to set the set point value.
    イオン濃度設定値: 感知されるイオン濃度。 セットポイント値を置くために、IfcPropertyBoundedValue.SetPointValueを使用する。
    이온 농도 설정: 감지되는 이온 농도. 세트 포인트 값을 넣으려면, IfcPropertyBoundedValue.SetPointValue를 사용하십시오.
