7.2.4.43 Pset_UnitaryControlElementPHistory

PSET_PERFORMANCEDRIVEN / IfcUnitaryControlElement

Properties for history and operating schedules of thermostats. HISTORY: Added in IFC4.

buildingSMART Data Dictionary

PSD-XML

  • Temperature
    P_REFERENCEVALUE / IfcTimeSeries / IfcThermodynamicTemperatureMeasure
    Temperature: Indicates the current measured temperature.
  • Mode
    P_REFERENCEVALUE / IfcTimeSeries / IfcIdentifier
    Mode: Indicates operation mode corresponding to Pset_UnitaryControlTypeCommon.Mode. For example, 'HEAT', 'COOL', 'AUTO'.
  • Fan
    P_REFERENCEVALUE / IfcTimeSeries / IfcLogical
    Fan: Indicates fan operation where True is on, False is off, and Unknown is automatic.
  • SetPoint
    P_REFERENCEVALUE / IfcTimeSeries / IfcIdentifier
    SetPoint: Indicates the temperature setpoint. For thermostats with setbacks or separate high and low setpoints, then the time series may contain a pair of values at each entry where the first value is the heating setpoint (low) and the second value is the cooling setpoint (high).
