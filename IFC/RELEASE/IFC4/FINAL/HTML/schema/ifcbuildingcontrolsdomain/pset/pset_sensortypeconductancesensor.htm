7.2.4.23 Pset_SensorTypeConductanceSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / CONDUCTANCESENSOR

A device that senses or detects electrical conductance. HISTORY: Added in IFC4.
電気伝導性を感知または検出するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • SetPointConductance
    P_BOUNDEDVALUE / IfcElectricConductanceMeasure
    SetPointConductance: The fill level value to be sensed. Use IfcPropertyBoundedValue.SetPointValue to set the set point value.
    電気伝導率設定値: 感知される電気伝導率。 セットポイント値を置くために、IfcPropertyBoundedValue.SetPointValueを使用する。
    전기 전도율 설정: 감지되는 전기 전도율. 세트 포인트 값을 넣으려면, IfcPropertyBoundedValue.SetPointValue를 사용하십시오.
