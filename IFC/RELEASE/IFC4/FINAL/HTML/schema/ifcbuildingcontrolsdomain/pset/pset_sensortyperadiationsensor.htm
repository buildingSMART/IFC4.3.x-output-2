7.2.4.37 Pset_SensorTypeRadiationSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / RADIATIONSENSOR

A device that senses or detects radiation. HISTORY: Added in IFC4.
放射線を感知または検出するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • SetPointRadiation
    P_BOUNDEDVALUE / IfcPowerMeasure
    SetPointRadiation: The radiation power value to be sensed. Use IfcPropertyBoundedValue.SetPointValue to set the set point value.
    放射線設定値: 感知される放射線量。 セットポイント値を置くために、IfcPropertyBoundedValue.SetPointValueを使用する。
    방사선 설정: 감지되는 방사선. 세트 포인트 값을 넣으려면, IfcPropertyBoundedValue.SetPointValue를 사용하십시오.
