7.2.4.39 Pset_SensorTypeSmokeSensor

PSET_TYPEDRIVENOVERRIDE / IfcSensor / SMOKESENSOR

A device that senses or detects smoke. HISTORY: PressureSensorSensorSetPoint (error in previous release) changed to SetPointConcentration. Range, accuracy and time constant deleted.
煙を感知または検出するデバイス。

buildingSMART Data Dictionary

PSD-XML

  • CoverageArea
    P_SINGLEVALUE / IfcAreaMeasure
    CoverageArea: The floor area that is covered by the sensor (typically measured as a circle whose center is at the location of the sensor).
    測定範囲: センサでカバーされている床面積。(通常、センターがセンサの位置にある円として測定される)
    측정 범위: 센서 커버되는 바닥 면적. (일반적으로 센터 센서의 위치에있는 원형으로 측정되는)
  • SetPointConcentration
    P_BOUNDEDVALUE / IfcPositiveRatioMeasure
    SetPointConcentration: The smoke concentration value to be sensed. Use IfcPropertyBoundedValue.SetPointValue to set the set point value.
    煙濃度設定値: 感知される煙濃度。 セットポイント値を置くために、IfcPropertyBoundedValue.SetPointValueを使用する。
    연기 농도 설정: 감지되는 연기 농도. 세트 포인트 값을 넣으려면, IfcPropertyBoundedValue.SetPointValue를 사용하십시오.
  • HasBuiltInAlarm
    P_SINGLEVALUE / IfcBoolean
    HasBuiltInAlarm: Indicates whether the smoke sensor is included as an element within a smoke alarm/sensor unit (TRUE) or not (FALSE).
    煙警報器に含まれているか: 煙センサーが煙警報センサユニットの中に要素として含まれているか(TRUE)、否か(FALSE)を識別する。
    연기 경보기에 포함여부: 연기 센서가 화재 경보 센서 유닛의 요소로 포함되어 있는지 (TRUE) 여부 (FALSE)를 확인한다.
