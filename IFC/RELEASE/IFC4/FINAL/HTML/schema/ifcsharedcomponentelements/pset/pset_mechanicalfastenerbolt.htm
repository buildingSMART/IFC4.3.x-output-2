6.3.4.12 Pset_MechanicalFastenerBolt

PSET_TYPEDRIVENOVERRIDE / IfcMechanicalFastener / BOLT

Properties related to bolt-type fasteners. The properties of a whole set with bolt, washers and nut may be provided. Note, it is usually not necessary to transmit these properties in case of standardized bolts. Instead, the standard is referred to.

buildingSMART Data Dictionary

PSD-XML

  • ThreadDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    ThreadDiameter: Nominal diameter of the thread, if different from the bolt's overall nominal diameter
  • ThreadLength
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    ThreadLength: Nominal length of the thread
  • NutsCount
    P_SINGLEVALUE / IfcCountMeasure
    NutsCount: Count of nuts to be mounted on one bolt
  • WashersCount
    P_SINGLEVALUE / IfcCountMeasure
    WashersCount: Count of washers to be mounted on one bolt
  • HeadShape
    P_SINGLEVALUE / IfcLabel
    HeadShape: Shape of the bolt's head, e.g. 'Hexagon', 'Countersunk', 'Cheese'
  • KeyShape
    P_SINGLEVALUE / IfcLabel
    KeyShape: If applicable, shape of the head's slot, e.g. 'Slot', 'Allen'
  • NutShape
    P_SINGLEVALUE / IfcLabel
    NutShape: Shape of the nut, e.g. 'Hexagon', 'Cap', 'Castle', 'Wing'
  • WasherShape
    P_SINGLEVALUE / IfcLabel
    WasherShape: Shape of the washers, e.g. 'Standard', 'Square'
