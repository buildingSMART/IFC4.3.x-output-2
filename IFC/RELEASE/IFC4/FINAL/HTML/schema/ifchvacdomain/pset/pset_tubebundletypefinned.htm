7.5.4.96 Pset_TubeBundleTypeFinned

PSET_TYPEDRIVENOVERRIDE / IfcTubeBundle / FINNED

Finned tube bundle type attributes. Contains the attributes related to the fins attached to a tube in a finned tube bundle such as is commonly found in coils.
フィンタイプチューブ束属性.一般にコイルに見られるように、フィンチューブ束内のチューブに付いているフィンに関する属性を含む

buildingSMART Data Dictionary

PSD-XML

  • Spacing
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Spacing: Distance between fins on a tube in the tube bundle.
    間隔: チューブ束内のフィン間の距離
  • Thickness
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Thickness: Thickness of the fin.
    厚さ: フィンの厚さ
  • ThermalConductivity
    P_SINGLEVALUE / IfcThermalConductivityMeasure
    ThermalConductivity: The thermal conductivity of the fin.
    熱伝導率: フィンの熱伝導率
  • Length
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Length: Length of the fin as measured parallel to the direction of airflow.
    長さ: 気流方向に平行に計られたフィンの長さ
  • Height
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Height: Length of the fin as measured perpendicular to the direction of airflow.
    高さ: 気流方向に垂直に計られたフィンの長さ
  • Diameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Diameter: Actual diameter of a fin for circular fins only.
    直径: 円形フィンのみ、フィンの実直径
  • FinCorrugatedType
    P_SINGLEVALUE / IfcLabel
    FinCorrugatedType: Description of a fin corrugated type.
    コルゲートタイプフィン: コルゲートタイプフィンの実直径
  • HasCoating
    P_SINGLEVALUE / IfcBoolean
    HasCoating: TRUE if the fin has a coating, FALSE if it does not.
    コーティング有り: フィンがコーティング有りの場合 TRUE、無しの場合FALSE
