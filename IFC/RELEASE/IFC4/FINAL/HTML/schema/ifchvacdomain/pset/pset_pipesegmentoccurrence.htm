7.5.4.75 Pset_PipeSegmentOccurrence

PSET_OCCURRENCEDRIVEN / IfcPipeSegment

Pipe segment occurrence attributes attached to an instance of IfcPipeSegment.

buildingSMART Data Dictionary

PSD-XML

  • InteriorRoughnessCoefficient
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    InteriorRoughnessCoefficient: The interior roughness coefficient of the pipe segment.
    内部粗度係数: 配管部の内部粗度係数
  • Color
    P_SINGLEVALUE / IfcLabel
    Color: The color of the pipe segment. Note: This is typically used only for plastic pipe segments. However, it may be used for any pipe segments with a painted surface which is not otherwise specified as a covering.
    色: 配管部の内部粗度係数　記：この語はプラスチック配管にのみ使われる。しかしながら、保護のためではない塗装された表面を持つ配管にも使われる。
  • Gradient
    P_SINGLEVALUE / IfcPositiveRatioMeasure
    Gradient: The gradient of the pipe segment.
    勾配: 配管部の勾配
  • InvertElevation
    P_SINGLEVALUE / IfcLengthMeasure
    InvertElevation: The invert elevation relative to the datum established for the project.
