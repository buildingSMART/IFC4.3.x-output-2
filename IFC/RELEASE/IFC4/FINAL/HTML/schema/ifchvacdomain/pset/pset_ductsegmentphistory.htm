7.5.4.40 Pset_DuctSegmentPHistory

PSET_PERFORMANCEDRIVEN / IfcDuctSegment

Duct segment performance history common attributes.
ダクト直管性能履歴共通属性。

buildingSMART Data Dictionary

PSD-XML

  • LossCoefficient
    P_REFERENCEVALUE / IfcTimeSeries / IfcReal
    LossCoefficient: Dimensionless loss coefficient used for calculating fluid resistance representing the ratio of total pressure loss to velocity pressure at a referenced cross-section.
    損失係数: 参照された断面での動圧に対する全圧損失の比を表わす流体抵抗の計算に使用される無次元の損失係数
  • AtmosphericPressure
    P_REFERENCEVALUE / IfcTimeSeries / IfcPressureMeasure
    AtmosphericPressure: Ambient atmospheric pressure.
    大気圧: 周囲の大気圧
  • LeakageCurve
    P_REFERENCEVALUE / IfcTimeSeries
    LeakageCurve: Leakage per unit length curve versus working pressure. If a scalar is expressed then it represents LeakageClass which is flowrate per unit area at a specified pressure rating (e.g., ASHRAE Fundamentals 2001 34.16.).
    漏れ曲線: 作動圧力に対する単位長さあたりの漏れ曲線。 スカラー値が表現されている場合は、所定の圧力（例えば、ASHRAE　Fundamentals 200134.16）における単位面積当たりの流量である漏れクラスを表す。
  • FluidFlowLeakage
    P_REFERENCEVALUE / IfcTimeSeries / IfcVolumetricFlowRateMeasure
    FluidFlowLeakage: Volumetric leakage flow rate.
    漏れ量: 体積漏れ流量
