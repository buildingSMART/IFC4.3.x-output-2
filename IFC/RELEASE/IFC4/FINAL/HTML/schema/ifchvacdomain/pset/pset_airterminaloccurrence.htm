7.5.4.3 Pset_AirTerminalOccurrence

PSET_OCCURRENCEDRIVEN / IfcAirTerminal

Air terminal occurrence attributes attached to an instance of IfcAirTerminal.
IfcAirTerminalのインスタンスの属性を設定。

buildingSMART Data Dictionary

PSD-XML

  • AirflowType
    P_ENUMERATEDVALUE / PEnum_AirTerminalAirflowType / PEnum_AirTerminalAirflowType: SUPPLYAIR, RETURNAIR, EXHAUSTAIR, OTHER, NOTKNOWN, UNSET
    AirflowType: Enumeration defining the functional type of air flow through the terminal.
    エアフロータイプ: ターミナルを通過する気流の機能タイプ（給気、還気、排気他）
    Type de débit d'air: Enumération définissant le type fonctionnel de débit à travers le terminal
  • AirFlowRate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    AirFlowRate: The actual airflow rate as designed.
  • Location
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AirTerminalLocation: SIDEWALLHIGH, SIDEWALLLOW, CEILINGPERIMETER, CEILINGINTERIOR, FLOOR, SILL, OTHER, NOTKNOWN, UNSET
    Location: Location (a single type of diffuser can be used for multiple locations); high means close to ceiling.
    位置: 制気口の取り付け位置（壁面高所・低部、天井ぺり、天井中央、床、床下他）
    Emplacement: Emplacement (un seul type de diffuseur peut être utilisé pour des emplaments multiples); Haut signifie proche du plafond.
