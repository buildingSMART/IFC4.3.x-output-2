7.5.4.69 Pset_PipeConnectionFlanged

PSET_TYPEDRIVENOVERRIDE / IfcPipeSegment

This property set is used to define the specifics of a flanged pipe connection used between occurrences of pipe segments and fittings.

buildingSMART Data Dictionary

PSD-XML

  • FlangeTable
    P_SINGLEVALUE / IfcLabel
    FlangeTable: Designation of the standard table to which the flange conforms.
    フランジ基準: フランジ形状の名称基準
  • FlangeStandard
    P_SINGLEVALUE / IfcLabel
    FlangeStandard: Designation of the standard describing the flange table.
    フランジ規格: フランジ規格を記述している基準
  • BoreSize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    BoreSize: The nominal bore of the pipe flange.
    フランジの内径のサイズ: フランジの呼び径
  • FlangeDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    FlangeDiameter: Overall diameter of the flange.
    フランジの直径: フランジの全直径
  • FlangeThickness
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    FlangeThickness: Thickness of the material from which the pipe bend is constructed.
    フランジの厚さ: パイプをつなぐ材料の厚み
  • NumberOfBoltholes
    P_SINGLEVALUE / IfcInteger
    NumberOfBoltholes: Number of boltholes in the flange.
    ボルト穴の数: フランジにあるボルト穴の数
  • BoltSize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    BoltSize: Size of the bolts securing the flange.
    ボルトの大きさ: フランジを締めるボルトの大きさ
  • BoltholePitch
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    BoltholePitch: Diameter of the circle along which the boltholes are placed.
    ボルト穴ピッチ: ボルト穴がある円の直径
