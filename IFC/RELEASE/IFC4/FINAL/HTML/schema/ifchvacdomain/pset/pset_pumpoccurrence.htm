7.5.4.80 Pset_PumpOccurrence

PSET_OCCURRENCEDRIVEN / IfcPump

Pump occurrence attributes attached to an instance of IfcPump.

buildingSMART Data Dictionary

PSD-XML

  • ImpellerDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    ImpellerDiameter: Diameter of pump impeller - used to scale performance of geometrically similar pumps.
    羽根直径: 幾何学的に似たポンプの性能を予測するのに使われる。
  • BaseType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_PumpBaseType: FRAME, BASE, NONE, OTHER, NOTKNOWN, UNSET
    BaseType: Defines general types of pump bases. FRAME: Frame. BASE: Base. NONE: There is no pump base, such as an inline pump. OTHER: Other type of pump base.
    基礎タイプ: ポンプ基礎の一般的な型を定義する(フレーム、(コンクリ)基礎、なし、その他)
  • DriveConnectionType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_PumpDriveConnectionType: DIRECTDRIVE, BELTDRIVE, COUPLING, OTHER, NOTKNOWN, UNSET
    DriveConnectionType: The way the pump drive mechanism is connected to the pump. DIRECTDRIVE: Direct drive. BELTDRIVE: Belt drive. COUPLING: Coupling. OTHER: Other type of drive connection.
    駆動接続タイプ: ポンプの動力機械がポンプに接続される方法(直動、ベルト、カップリング、その他)
