7.5.4.100 Pset_ValvePHistory

PSET_PERFORMANCEDRIVEN / IfcValve

Valve performance history common attributes of a typical 2 port pattern type valve.
バルブの履歴

buildingSMART Data Dictionary

PSD-XML

  • PercentageOpen
    P_REFERENCEVALUE / IfcTimeSeries / IfcPositiveRatioMeasure
    PercentageOpen: The ratio between the amount that the valve is open to the full open position of the valve.
    パーセント開度: 全開時に対する開度量の比率。
  • MeasuredFlowRate
    P_REFERENCEVALUE / IfcTimeSeries / IfcMassFlowRateMeasure
    MeasuredFlowRate: The rate of flow of a fluid measured across the valve.
    計測流量: バルブを通過する流体の計測された流量
  • MeasuredPressureDrop
    P_REFERENCEVALUE / IfcTimeSeries / IfcPressureMeasure
    MeasuredPressureDrop: The actual pressure drop in the fluid measured across the valve.
    計測圧力降下: バルブを通過する際の計測された圧力降下
