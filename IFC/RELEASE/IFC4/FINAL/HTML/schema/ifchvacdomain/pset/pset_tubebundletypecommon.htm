7.5.4.95 Pset_TubeBundleTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcTubeBundle

Tube bundle type common attributes.
チューブ束タイプ共通プロパティ属性設定。

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1').
    参照記号: このプロジェクトにおける参照記号(例：A-1)。分類コードではなく内部で使用されるプロジェクトタイプとして使用されるもの。
  • Status
    P_ENUMERATEDVALUE / IfcLabel / PEnum_Status: NEW, EXISTING, DEMOLISH, TEMPORARY, OTHER, NOTKNOWN, UNSET
    Status: Status of the element, predominately used in renovation or retrofitting projects. The status can be assigned to as "New" - element designed as new addition, "Existing" - element exists and remains, "Demolish" - element existed but is to be demolished, "Temporary" - element will exists only temporary (like a temporary support structure).
    状態: 要素（主にリノベーションまたは改修プロジェクトにおいて）の状態。 状態は、「新規(New)」－新しく追加される要素。「既存」－要素は存在し、かつ残りもの。「破壊」－要素は存在したが、廃棄されるもの。「一時的」－一時的に存在する要素（一時的にサポートしている構造のようなもの）。
  • NumberOfRows
    P_SINGLEVALUE / IfcInteger
    NumberOfRows: Number of tube rows in the tube bundle assembly.
    列数: チューブの集合の組立におけるチューブ列数
  • StaggeredRowSpacing
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    StaggeredRowSpacing: Staggered tube row spacing.
    互い違いの列間隔: 互い違いのチューブ列間隔
  • InLineRowSpacing
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    InLineRowSpacing: In-line tube row spacing.
    インライン列間隔: インラインチューブ列間隔
  • NumberOfCircuits
    P_SINGLEVALUE / IfcInteger
    NumberOfCircuits: Number of parallel fluid tube circuits.
    平行流回路数: 平行流チューブ回路数
  • FoulingFactor
    P_SINGLEVALUE / IfcThermalResistanceMeasure
    FoulingFactor: Fouling factor of the tubes in the tube bundle.
    汚れ係数: チューブ束のチューブ汚れ係数
  • ThermalConductivity
    P_SINGLEVALUE / IfcThermalConductivityMeasure
    ThermalConductivity: The thermal conductivity of the tube.
    熱伝導率: チューブの熱伝導率
  • Length
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Length: Length of the tubes in the tube bundle.
    長さ: チューブ束のチューブ長さ
  • Volume
    P_SINGLEVALUE / IfcVolumeMeasure
    Volume: Total volume of fluid in the tubes and their headers.
    流量: チューブとヘッダー内の総流量
  • NominalDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalDiameter: Nominal diameter or width of the tubes in the tube bundle.
    公称直径: チューブ束内のチューブ公称直径又は幅
  • OutsideDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    OutsideDiameter: Actual outside diameter of the tube in the tube bundle.
    外径: チューブ束内のチューブ実外径
  • InsideDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    InsideDiameter: Actual inner diameter of the tube in the tube bundle.
    内径: チューブ束内のチューブ実内径
  • HorizontalSpacing
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    HorizontalSpacing: Horizontal spacing between tubes in the tube bundle.
    水平間隔: チューブ束内のチューブ間水平間隔
  • VerticalSpacing
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    VerticalSpacing: Vertical spacing between tubes in the tube bundle.
    垂直間隔: チューブ束内のチューブ間垂直間隔
  • HasTurbulator
    P_SINGLEVALUE / IfcBoolean
    HasTurbulator: TRUE if the tube has a turbulator, FALSE if it does not.
    かくはん器有り: かくはん器有りの時 TRUE、無しの時 FALSE
