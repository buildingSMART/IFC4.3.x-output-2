7.5.4.53 Pset_FilterPHistory

PSET_PERFORMANCEDRIVEN / IfcFilter

Filter performance history attributes.

buildingSMART Data Dictionary

PSD-XML

  • CountedEfficiency
    P_REFERENCEVALUE / IfcTimeSeries / IfcReal
    CountedEfficiency: Filter efficiency based the particle counts concentration before and after filter against particles with certain size distribution.
  • WeightedEfficiency
    P_REFERENCEVALUE / IfcTimeSeries / IfcReal
    WeightedEfficiency: Filter efficiency based the particle weight concentration before and after filter against particles with certain size distribution.
  • ParticleMassHolding
    P_REFERENCEVALUE / IfcTimeSeries / IfcMassMeasure
    ParticleMassHolding: Mass of particle holding in the filter.
