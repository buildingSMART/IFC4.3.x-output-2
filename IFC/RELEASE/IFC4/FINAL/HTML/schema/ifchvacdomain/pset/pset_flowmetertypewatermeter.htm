7.5.4.63 Pset_FlowMeterTypeWaterMeter

PSET_TYPEDRIVENOVERRIDE / IfcFlowMeter / WATERMETER

Device that measures, indicates and sometimes records, the volume of water that passes through it without interrupting the flow.

buildingSMART Data Dictionary

PSD-XML

  • Type
    P_ENUMERATEDVALUE / IfcLabel / PEnum_WaterMeterType: COMPOUND, INFERENTIAL, PISTON, OTHER, NOTKNOWN, UNSET
    Type: Defines the allowed values for selection of the flow meter operation type.
  • ConnectionSize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    ConnectionSize: Defines the size of inlet and outlet pipe connections to the meter.
  • MaximumFlowRate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    MaximumFlowRate: Maximum rate of flow which the meter is expected to pass.
  • MaximumPressureLoss
    P_SINGLEVALUE / IfcPressureMeasure
    MaximumPressureLoss: Pressure loss expected across the meter under conditions of maximum flow.
  • BackflowPreventerType

    BackflowPreventerType: Identifies the type of backflow preventer installed to prevent the backflow of contaminated or polluted water from an irrigation/reticulation system to a potable water supply.
