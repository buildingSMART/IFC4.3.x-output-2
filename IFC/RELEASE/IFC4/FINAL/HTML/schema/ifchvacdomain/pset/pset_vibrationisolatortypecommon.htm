7.5.4.111 Pset_VibrationIsolatorTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcVibrationIsolator

Vibration isolator type common attributes.
振動絶縁体の共通属性

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1').
    参照記号: このプロジェクトにおける参照記号(例：A-1)。分類コードではなく内部で使用されるプロジェクトタイプとして使用されるもの。
  • VibrationTransmissibility
    P_SINGLEVALUE / IfcPositiveRatioMeasure
    VibrationTransmissibility: The vibration transmissibility percentage.
    振動伝達: 振動伝達割合
  • IsolatorStaticDeflection
    P_SINGLEVALUE / IfcLengthMeasure
    IsolatorStaticDeflection: Static deflection of the vibration isolator.
    振動絶縁材静的たわみ: 振動絶縁材の静的たわみ
  • IsolatorCompressibility
    P_SINGLEVALUE / IfcRatioMeasure
    IsolatorCompressibility: The compressibility of the vibration isolator.
    振動絶縁材の圧縮率: 振動絶縁材の圧縮率の圧縮率
  • Height
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    Height: Height of the vibration isolator before tha application of load.
    高さ: 負荷を掛ける前の振動絶縁材の高さ
  • MaximumSupportedWeight
    P_SINGLEVALUE / IfcMassMeasure
    MaximumSupportedWeight: The maximum weight that can be carried by the vibration isolator.
    最高支持重量: 振動絶縁材で支えられる最高重量
