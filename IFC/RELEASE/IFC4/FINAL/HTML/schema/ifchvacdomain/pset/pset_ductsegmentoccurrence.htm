7.5.4.39 Pset_DuctSegmentOccurrence

PSET_OCCURRENCEDRIVEN / IfcDuctSegment

Duct segment occurrence attributes attached to an instance of IfcDuctSegment.
IfcDuctSegmentの値に関連づいたダクト直管の属性。

buildingSMART Data Dictionary

PSD-XML

  • InteriorRoughnessCoefficient
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    InteriorRoughnessCoefficient: The interior roughness of the duct fitting material.
    内面粗さ係数: ダクト継手材料の内面粗さ
  • HasLiner
    P_SINGLEVALUE / IfcBoolean
    HasLiner: TRUE if the fitting has interior duct insulating lining, FALSE if it does not.
    内張り有無: 内貼り保温ダクト内面にあるときにTRUE。無い時にFALSE
  • Color
    P_SINGLEVALUE / IfcLabel
    Color: The color of the duct segment. Note: This is typically used for any duct segments with a painted surface which is not otherwise specified as a covering.
    色: ダクト継手の色 メモ：塗装されているときに使用される。他の場合は仕上げとして定義
