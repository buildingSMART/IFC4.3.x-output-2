7.5.4.82 Pset_PumpTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcPump

Common attributes of a pump type.
ポンプタイプ共通属性

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1').
    参照記号: このプロジェクトにおける参照記号(例：A-1)。分類コードではなく内部で使用されるプロジェクトタイプとして使用されるもの。
  • Status
    P_ENUMERATEDVALUE / IfcLabel / PEnum_Status: NEW, EXISTING, DEMOLISH, TEMPORARY, OTHER, NOTKNOWN, UNSET
    Status: Status of the element, predominately used in renovation or retrofitting projects. The status can be assigned to as "New" - element designed as new addition, "Existing" - element exists and remains, "Demolish" - element existed but is to be demolished, "Temporary" - element will exists only temporary (like a temporary support structure).
    状態: 要素（主にリノベーションまたは改修プロジェクトにおいて）の状態。 状態は、「新規(New)」－新しく追加される要素。「既存」－要素は存在し、かつ残りもの。「破壊」－要素は存在したが、廃棄されるもの。「一時的」－一時的に存在する要素（一時的にサポートしている構造のようなもの）。
  • FlowRateRange
    P_BOUNDEDVALUE / IfcMassFlowRateMeasure
    FlowRateRange: Allowable range of volume of fluid being pumped against the resistance specified.
    流量範囲: 指定された抵抗に対してポンプでくみ上げ可能な流対量の許容範囲
  • FlowResistanceRange
    P_BOUNDEDVALUE / IfcPressureMeasure
    FlowResistanceRange: Allowable range of frictional resistance against which the fluid is being pumped.
    流体抵抗の範囲: 流体をポンプでくみ上げる際の摩擦抵抗の許容範囲
  • ConnectionSize
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    ConnectionSize: The connection size of the to and from the pump.
    接続サイズ: ポンプの入出の接続サイズ
  • TemperatureRange
    P_BOUNDEDVALUE / IfcThermodynamicTemperatureMeasure
    TemperatureRange: Allowable operational range of the fluid temperature.
    温度範囲: 流体温度の許容範囲
  • NetPositiveSuctionHead
    P_SINGLEVALUE / IfcPressureMeasure
    NetPositiveSuctionHead: Minimum liquid pressure at the pump inlet to prevent cavitation.
    正味吸入側水頭: キャビテーションを防ぐポンプ入口の最小限の流体圧力
  • NominalRotationSpeed
    P_SINGLEVALUE / IfcRotationalFrequencyMeasure
    NominalRotationSpeed: Pump rotational speed under nominal conditions.
    通常の回転速度: 多目的な状況の下でのポンプの回転速度
