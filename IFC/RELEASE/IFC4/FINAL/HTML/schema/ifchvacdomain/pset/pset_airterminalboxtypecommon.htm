7.5.4.2 Pset_AirTerminalBoxTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcAirTerminalBox

Air terminal box type common attributes.
ターミナルボックスタイプの共通属性。

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1'), provided, if there is no classification reference to a recognized classification system used.
    参照記号: このプロジェクトにおける参照記号(例：A-1)。分類コードではなく内部で使用されるプロジェクトタイプとして使用されるもの。
    Référence: Identification de référence pour ce type spécifique à ce projet, c'est-à-dire type'A-1', fourni à partir du moment où, s'il n'y a pas de référence de classification par rapport à un système de classification reconnu et en usage.
  • Status
    P_ENUMERATEDVALUE / IfcLabel / PEnum_Status: NEW, EXISTING, DEMOLISH, TEMPORARY, OTHER, NOTKNOWN, UNSET
    Status: Status of the element, predominately used in renovation or retrofitting projects. The status can be assigned to as "New" - element designed as new addition, "Existing" - element exists and remains, "Demolish" - element existed but is to be demolished, "Temporary" - element will exists only temporary (like a temporary support structure).
    状態: 要素（主にリノベーションまたは改修プロジェクトにおいて）の状態。 状態は、「新規(New)」－新しく追加される要素。「既存」－要素は存在し、かつ残りもの。「破壊」－要素は存在したが、廃棄されるもの。「一時的」－一時的に存在する要素（一時的にサポートしている構造のようなもの）。
    Etat: Etat de l'élément, utilisé avant tout pour les projets de rénovation et réaménagement. L'état assigné peut être "Nouveau" - l'élément prévu pour du neuf, "Existant" - l'élément existait et est maintenu, "Démoli" - l'élément existait mais doit être démoli/supprimé, "Provisoire" - l'élément existera à titre provisoire seulement (comme un support structurel par exemple).
  • AirflowRateRange
    P_BOUNDEDVALUE / IfcVolumetricFlowRateMeasure
    AirflowRateRange: Range of airflow that can be delivered.
    風量範囲: 送風できる風量の範囲
    Domaine de débit d'air: Plage de débit d'air pouvant être fourni.
  • AirPressureRange
    P_BOUNDEDVALUE / IfcPressureMeasure
    AirPressureRange: Allowable air static pressure range at the entrance of the air terminal box.
    空気圧範囲: ターミナル入り口での許容静圧範囲
    Plage de pression d'air: Plage admise de la pression statique de l'air à l'entrée du registre terminal de ventilation
  • NominalAirFlowRate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    NominalAirFlowRate: Nominal airflow rate.
    設計風量範囲: 設計風量範囲
    Débit d'air nominal: Débit d'air nominal
  • ArrangementType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AirTerminalBoxArrangementType: SINGLEDUCT, DUALDUCT, OTHER, NOTKNOWN, UNSET
    ArrangementType: Terminal box arrangement. SingleDuct: Terminal box receives warm or cold air from a single air supply duct. DualDuct: Terminal box receives warm and cold air from separate air supply ducts.
    ターミナル形式: ターミナルボックスの形式。 単一ダクト：単一のダクトから、温風または冷風を受け取る デュアルダクト：温風、冷風を分離されたダクトから受け取る
    Type de configuration: Configuration du registre terminal. Conduit unique: le registre terminal reçoit de l'air chaud ou froid depuis un conduit unique d'amenée d'air
  • ReheatType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AirTerminalBoxReheatType: ELECTRICALREHEAT, WATERCOILREHEAT, STEAMCOILREHEAT, GASREHEAT, NONE, OTHER, NOTKNOWN, UNSET
    ReheatType: Terminal box reheat type.
    再熱形式: ターミナルの再熱方式 （電気、水コイル、蒸気コイル、ガス加熱．．．）
    Type de réchauffage: Type de réchauffage d'un registre terminal de ventilation
  • HasSoundAttenuator
    P_SINGLEVALUE / IfcBoolean
    HasSoundAttenuator: Terminal box has a sound attenuator.
    消音有無: ターミナルに消音があるか否か　（あればTRUE)
    Possède correction acoustique: Le registre terminal possède une correction acoustique
  • HasReturnAir
    P_SINGLEVALUE / IfcBoolean
    HasReturnAir: Terminal box has return air mixed with supply air from duct work.
    還気有無: ターミナルで還気を混合しているか否か（していればTRUE)
    Possède air repris: Le registre terminal a son air de reprise mélangé avec une amenée d'air issu du réseau de ventilation
  • HasFan
    P_SINGLEVALUE / IfcBoolean
    HasFan: Terminal box has a fan inside (fan powered box).
    送風機有無: 内部に送風機を持つ時にTRUE
    Possède ventilateur: Le registre terminal possède dans son intérieur un ventilateur (registre motorisé)
  • NominalInletAirPressure
    P_SINGLEVALUE / IfcPressureMeasure
    NominalInletAirPressure: Nominal airflow inlet static pressure.
    設計入口空気圧: 入口静圧の設計値
    Pression nominale à l'entrée d'air: Pression statique en débit d'air nominal à l'entrée
  • NominalDamperDiameter
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    NominalDamperDiameter: Nominal damper diameter.
    設計ダンパ直径: ダンパ直径の設計値
    Diamètre nominal clapet: Diamètre nominal clapet
  • HousingThickness
    P_SINGLEVALUE / IfcLengthMeasure
    HousingThickness: Air terminal box housing material thickness.
    ハウジング板厚: ターミナルのハウジング材の板厚
    Epaisseur de l'enveloppe: Epaisseur du matériau réalisant l'enveloppe du registre terminal de ventilation
  • OperationTemperatureRange
    P_BOUNDEDVALUE / IfcThermodynamicTemperatureMeasure
    OperationTemperatureRange: Allowable operational range of the ambient air temperature.
    動作温度範囲: 許容周囲温度範囲
    Plage de température d'exploitation: Plage opérationnelle possible de la température de l'air ambiant
  • ReturnAirFractionRange
    P_BOUNDEDVALUE / IfcPositiveRatioMeasure
    ReturnAirFractionRange: Allowable return air fraction range as a fraction of discharge airflow.
    還気風量比: 送風量の一部としての許容還気風量
    Plage pour la fraction d'air repris: Plage possiblede la fraction d'air repris en tant que fraction de l'air rejeté
