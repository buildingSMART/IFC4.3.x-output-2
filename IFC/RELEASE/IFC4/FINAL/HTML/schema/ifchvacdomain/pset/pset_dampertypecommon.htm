7.5.4.31 Pset_DamperTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcDamper

Damper type common attributes.
ダンパー型の共通プロパティ属性設定。

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1'), provided, if there is no classification reference to a recognized classification system used.
    参照記号: このプロジェクトにおける参照記号(例：A-1)。分類コードではなく内部で使用されるプロジェクトタイプとして使用されるもの。
  • Status
    P_ENUMERATEDVALUE / IfcLabel / PEnum_Status: NEW, EXISTING, DEMOLISH, TEMPORARY, OTHER, NOTKNOWN, UNSET
    Status: Status of the element, predominately used in renovation or retrofitting projects. The status can be assigned to as "New" - element designed as new addition, "Existing" - element exists and remains, "Demolish" - element existed but is to be demolished, "Temporary" - element will exists only temporary (like a temporary support structure).
    状態: 要素（主にリノベーションまたは改修プロジェクトにおいて）の状態。 状態は、「新規(New)」－新しく追加される要素。「既存」－要素は存在し、かつ残りもの。「破壊」－要素は存在したが、廃棄されるもの。「一時的」－一時的に存在する要素（一時的にサポートしている構造のようなもの）。
  • Operation
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DamperOperation: AUTOMATIC, MANUAL, OTHER, NOTKNOWN, UNSET
    Operation: The operational mechanism for the damper operation.
  • Orientation
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DamperOrientation: VERTICAL, HORIZONTAL, VERTICALORHORIZONTAL, OTHER, NOTKNOWN, UNSET
    Orientation: The intended orientation for the damper as specified by the manufacturer.
  • BladeMaterial
    P_REFERENCEVALUE / IfcMaterialDefinition
    BladeMaterial: The material from which the damper blades are constructed.
  • BladeThickness
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    BladeThickness: The thickness of the damper blade.
  • SealMaterial
    P_REFERENCEVALUE / IfcMaterialDefinition
    SealMaterial: The material from which the damper seals are constructed.
  • BladeAction
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DamperBladeAction: FOLDINGCURTAIN, PARALLEL, OPPOSED, SINGLE, OTHER, NOTKNOWN, UNSET
    BladeAction: Blade action.
  • BladeShape
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DamperBladeShape: FLAT, FABRICATEDAIRFOIL, EXTRUDEDAIRFOIL, OTHER, NOTKNOWN, UNSET
    BladeShape: Blade shape. Flat means triple V-groove.
  • BladeEdge
    P_ENUMERATEDVALUE / IfcLabel / PEnum_DamperBladeEdge: CRIMPED, UNCRIMPED, OTHER, NOTKNOWN, UNSET
    BladeEdge: Blade edge.
  • NumberofBlades
    P_SINGLEVALUE / IfcInteger
    NumberofBlades: Number of blades.
  • FaceArea
    P_SINGLEVALUE / IfcAreaMeasure
    FaceArea: Face area open to the airstream.
  • MaximumAirFlowRate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    MaximumAirFlowRate: Maximum allowable air flow rate.
  • TemperatureRange
    P_BOUNDEDVALUE / IfcThermodynamicTemperatureMeasure
    TemperatureRange: Temperature range.
  • MaximumWorkingPressure
    P_SINGLEVALUE / IfcPressureMeasure
    MaximumWorkingPressure: Maximum working pressure.
  • TemperatureRating
    P_SINGLEVALUE / IfcThermodynamicTemperatureMeasure
    TemperatureRating: Temperature rating.
  • NominalAirFlowRate
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    NominalAirFlowRate: Nominal air flow rate.
  • OpenPressureDrop
    P_SINGLEVALUE / IfcPressureMeasure
    OpenPressureDrop: Total pressure drop across damper.
  • LeakageFullyClosed
    P_SINGLEVALUE / IfcVolumetricFlowRateMeasure
    LeakageFullyClosed: Leakage when fully closed.
  • LossCoefficentCurve
    P_TABLEVALUE / IfcPositivePlaneAngleMeasure / IfcReal
    LossCoefficentCurve: Loss coefficient – blade position angle curve; ratio of pressure drop to velocity pressure versus blade angle; C = f (blade angle position).
  • LeakageCurve
    P_TABLEVALUE / IfcVolumetricFlowRateMeasure / IfcPressureMeasure
    LeakageCurve: Leakage versus pressure drop; Leakage = f (pressure).
  • RegeneratedSoundCurve
    P_TABLEVALUE / IfcVolumetricFlowRateMeasure / IfcSoundPressureMeasure
    RegeneratedSoundCurve: Regenerated sound versus air flow rate.
  • FrameType
    P_SINGLEVALUE / IfcLabel
    FrameType: The type of frame used by the damper (e.g., Standard, Single Flange, Single Reversed Flange, Double Flange, etc.).
  • FrameDepth
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    FrameDepth: The length (or depth) of the damper frame.
  • FrameMaterial
    P_REFERENCEVALUE / IfcMaterialDefinition
    FrameMaterial: The material from which the damper frame is constructed.
  • FrameThickness
    P_SINGLEVALUE / IfcPositiveLengthMeasure
    FrameThickness: The thickness of the damper frame material.
  • CloseOffRating
    P_SINGLEVALUE / IfcPressureMeasure
    CloseOffRating: Close off rating.
