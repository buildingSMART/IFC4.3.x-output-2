7.4.4.56 Pset_ProtectiveDeviceTrippingUnitTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcProtectiveDeviceTrippingUnit

Common information concerning tripping units that area associated with protective devices
保護装置に関連付けられているトリップ機能に関する共通情報。

buildingSMART Data Dictionary

PSD-XML

  • Reference
    P_SINGLEVALUE / IfcIdentifier
    Reference: Reference ID for this specified type in this project (e.g. type 'A-1'), provided, if there is no classification reference to a recognized classification system used.
    参照: 当該プロジェクトで定義する形式の参照ID（例：A-1)、承認された分類に存在しないときに使用される。
    참조: 해당 프로젝트에 정의된 형식의 참조 ID (예 : A-1) 승인된 분류에 존재하지 않을 때 사용된다.
  • Status
    P_ENUMERATEDVALUE / IfcLabel / PEnum_Status: NEW, EXISTING, DEMOLISH, TEMPORARY, OTHER, NOTKNOWN, UNSET
    Status: Status of the element, predominately used in renovation or retrofitting projects. The status can be assigned to as "New" - element designed as new addition, "Existing" - element exists and remains, "Demolish" - element existed but is to be demolished, "Temporary" - element will exists only temporary (like a temporary support structure).
    状態: 要素（主にリノベーションまたは改修プロジェクトにおいて）の状態。 状態は、「新規(New)」－新しく追加される要素。「既存」－要素は存在し、かつ残りもの。「破壊」－要素は存在したが、廃棄されるもの。「一時的」－一時的に存在する要素（一時的にサポートしている構造のようなもの）。
  • Standard
    P_SINGLEVALUE / IfcLabel
    Standard: The designation of the standard applicable for the definition of the characteristics of the tripping_unit.
    特性定義: トリッピング装置の特性定義のための標準的な適用の指定。
    특성 정의: 토릿삔구 장치의 특성 정의에 대한 표준 적용 지정.
  • UseInDiscrimination
    P_SINGLEVALUE / IfcBoolean
    UseInDiscrimination: An indication whether the time/current tripping information can be applied in a discrimination analysis or not.
    使用方法: トリップ情報を時間か電流かどちらで判断するか。
    사용방법: 트립 정보를 시간 또는 전류가 어디에서 결정하는가?
  • AtexVerified
    P_SINGLEVALUE / IfcBoolean
    AtexVerified: An indication whether the tripping_unit is verified to be applied in EX-environment or not.
    アテックス認証: トリップ装置がEX-環境で適用されるかどうか。
    EX -환경 인증: 트립 장치가 EX-환경에 적용되는지 여부
  • OldDevice
    P_SINGLEVALUE / IfcBoolean
    OldDevice: Indication whether the protection_ unit is out-dated or not. If not out-dated, the device is still for sale.
    販売中止装置: 基準に適合されていて販売されているかどうか。
    판매중지 장치: 기준에 적합하여 판매하는지에 대한 여부
  • LimitingTerminalSize
    P_SINGLEVALUE / IfcAreaMeasure
    LimitingTerminalSize: The maximum terminal size capacity of the device.
    接続限界値: 装置に接続される最大サイズ。
    연결 한계: 장치에 연결되는 최대 크기입니다.
