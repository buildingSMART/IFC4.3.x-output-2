7.4.4.10 Pset_AudioVisualApplianceTypeTuner

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / TUNER

An audio-visual tuner is a device that demodulates a signal into a stream of audio and/or video. HISTORY: Added in IFC4.
音響と映像の信号を変換する装置。

buildingSMART Data Dictionary

PSD-XML

  • TunerType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualTunerType: AUDIO, VIDEO, OTHER, NOTKNOWN, UNSET.
    TunerType: Indicates the tuner type.
    チューナータイプ: チューナータイプを示す。
