7.4.4.3 Pset_AudioVisualApplianceTypeCamera

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / CAMERA

An audio-visual camera is a device that captures video, such as for security. HISTORY: Added in IFC4.
セキュリティシステム向けの映像を撮影する装置。

buildingSMART Data Dictionary

PSD-XML

  • CameraType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualCameraType: PHOTO, VIDEO, AUDIOVIDEO, OTHER, NOTKNOWN, UNSET.
    CameraType: Indicates the type of camera.
    カメラ形式: カメラの形式を示す。
    카메라 형식: 카메라의 형식을 보여준다.
  • IsOutdoors
    P_SINGLEVALUE / IfcBoolean
    IsOutdoors: Indicates if camera is designed to be used outdoors.
    屋外対応の可否: 屋外利用が可能かどうかを示す。
    실외 여부: 옥외 이용이 가능한지 여부를 나타냅니다.
  • VideoResolutionWidth
    P_SINGLEVALUE / IfcInteger
    VideoResolutionWidth: Indicates the number of horizontal pixels (the largest native video resolution width).
    水平解像度: 水平方向のピクセル数。
    수평 해상도: 가로 픽셀 수입니다.
  • VideoResolutionHeight
    P_SINGLEVALUE / IfcInteger
    VideoResolutionHeight: Indicates the number of vertical pixels (the largest native video resolution height).
    垂直解像度: 垂直方向のピクセル数。
    수직 해상도: 세로 픽셀 수.
  • VideoResolutionMode
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    VideoResolutionMode: Indicates video resolution modes.
    ビデオ解像度モード: ビデオ解像度モードを示す。
    비디오 해상도 모드: 비디오 해상도를 보여준다.
  • VideoCaptureInterval
    P_TABLEVALUE / IfcIdentifier / IfcTimeMeasure
    VideoCaptureInterval: Indicates video frame capture time intervals.
    撮影間隔: 撮影間隔を示す。
  • PanTiltZoomPreset
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    PanTiltZoomPreset: Indicates pan/tilt/zoom position presets.
    パン・チルト・ズーム初期設定: パン・チルト・ズーム機能の初期設定。
  • PanHorizontal
    P_BOUNDEDVALUE / IfcLengthMeasure
    PanHorizontal: Indicates horizontal range for panning.
    パン水平方向可動範囲: 水平方向の可動範囲を示す。
  • PanVertical
    P_BOUNDEDVALUE / IfcLengthMeasure
    PanVertical: Indicates vertical range for panning.
    パン垂直方向可動範囲: 垂直方向の可動範囲を示す。
  • TiltHorizontal
    P_BOUNDEDVALUE / IfcPlaneAngleMeasure
    TiltHorizontal: Indicates horizontal range for pivoting, where positive values indicate the camera rotating clockwise,
    チルト水平方向可動角度: チルト水平の可動角度を示す。
  • TiltVertical
    P_BOUNDEDVALUE / IfcPlaneAngleMeasure
    TiltVertical: Indicates vertical range for pivoting, where 0.0 is level, +90 degrees is looking up, -90 degrees is looking down.
    チルト垂直方向可動角度: チルト垂直の可動角度を示す。
  • Zoom
    P_BOUNDEDVALUE / IfcPositiveLengthMeasure
    Zoom: Indicates the zoom range.
    ズーム: ズーム可能範囲（倍率）を示す。
