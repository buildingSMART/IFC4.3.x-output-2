7.4.4.9 Pset_AudioVisualApplianceTypeSpeaker

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / SPEAKER

An audio-visual speaker is a device that converts amplified audio signals into sound waves. HISTORY: Added in IFC4.
音響信号を音波に変換する装置。

buildingSMART Data Dictionary

PSD-XML

  • SpeakerType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualSpeakerType: FULLRANGE, MIDRANGE, WOOFER, TWEETER, COAXIAL, OTHER, NOTKNOWN, UNSET.
    SpeakerType: Indicates the type of speaker.
    スピーカータイプ: スピーカーのタイプを示す。
    스피커 타입: 스피커의 타입을 나타낸다.
  • SpeakerMounting
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualSpeakerMounting: FREESTANDING, CEILING, WALL, OUTDOOR, OTHER, NOTKNOWN, UNSET.
    SpeakerMounting: Indicates how the speaker is designed to be mounted.
    取付可能方法: 取付可能な方法を示す。
    설치 가능 방법: 붙일 수있는 방법을 보여준다.
  • SpeakerDriverSize
    P_TABLEVALUE / IfcIdentifier / IfcPositiveLengthMeasure
    SpeakerDriverSize: Indicates the number of drivers and their sizes.
    スピーカードライバサイズ: ドライバユニットと数を示す。
    스피커 드라이버: 드라이버 유닛과 수를 나타낸다
  • FrequencyResponse
    P_TABLEVALUE / IfcFrequencyMeasure / IfcSoundPowerMeasure
    FrequencyResponse: Indicates the output over a specified range of frequencies.
    周波数応答: 周波数範囲での出力を示す。
    주파수 응답: 주파수 범위에서 출력을 보여준다.
  • Impedence
    P_SINGLEVALUE / IfcFrequencyMeasure
    Impedence: Indicates the speaker impedence.
    インピーダンス値: インピーダンス値を示す。
    임피던스: 임피던스 값을 나타낸다.
