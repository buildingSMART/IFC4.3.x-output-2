7.4.4.73 Pset_SwitchingDeviceTypeKeypad

PSET_TYPEDRIVENOVERRIDE / IfcSwitchingDevice / KEYPAD

A keypad is a switch supporting multiple functions. HISTORY: Added in IFC4.
キーパッドは複数の機能をサポートするスイッチ。 履歴： IFC4に追加。
