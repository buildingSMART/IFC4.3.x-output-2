7.4.4.6 Pset_AudioVisualApplianceTypePlayer

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / PLAYER

An audio-visual player is a device that plays stored media into a stream of audio and/or video, such as camera footage in security systems, background audio in retail areas, or media presentations in conference rooms or theatres. HISTORY: Added in IFC4.
セキュリティーシステムのカメラや店舗などのBGMシステム、または劇場や会議室ないのプレゼンテーションシステムのような収容された音響映像信号を表示・放送する装置。

buildingSMART Data Dictionary

PSD-XML

  • PlayerType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualPlayerType: AUDIO, VIDEO, OTHER, NOTKNOWN, UNSET.
    PlayerType: Indicates the type of player.
    プレイヤー形式: 再生可能な形式を示す。
    플레이어 형식: 재생 가능한 형식을 보여준다.
  • PlayerMediaEject
    P_SINGLEVALUE / IfcBoolean
    PlayerMediaEject: Indicates whether the media can be ejected from the player (if physical media).
    メディア取り出し可否: メディアを取り出すことができるかどうかを示す。
    미디어 꺼내기 여부: 미디어를 꺼낼 수 있는지 여부를 나타낸다.
  • PlayerMediaFormat
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    PlayerMediaFormat: Indicates supported media formats.
    メディアフォーマット: サポートされているメディアのフォーマットを示す。
    미디어 포맷: 지원되는 미디어 형식을 보여준다.
