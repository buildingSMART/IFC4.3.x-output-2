7.4.4.46 Pset_ProtectiveDeviceBreakerUnitTypeMCB

PSET_TYPEDRIVENOVERRIDE / IfcProtectiveDevice / CIRCUITBREAKER

A coherent set of attributes representing the breaking capacities of an MCB. Note - A protective device may be associated with different instances of this property set providing information related to different basic characteristics.

buildingSMART Data Dictionary

PSD-XML

  • PowerLoss
    P_SINGLEVALUE / IfcPowerMeasure
    PowerLoss: The power loss in [W] per pole of the MCB when the nominal current is flowing through the MCB.
    電力損失: 定格電流がMCBに流れている時のMCBの極当たりの電力損失[W]。
    전력 손실: 정격 전류가 MCB 흐르고있을 때의 MCB 극 당 전력 손실 [W].
  • VoltageLevel
    P_ENUMERATEDVALUE / IfcLabel / PEnum_VoltageLevels: U230, U400, U440, U525, U690, U1000, OTHER, NOTKNOWN, UNSET
    VoltageLevel: The voltage levels for which the data of the instance is valid. More than one value may be selected in the enumeration.
    電圧レベル: 電圧レベルを選択。
    전압 레벨: 전압레벨을 선택합니다.
  • NominalCurrents
    P_LISTVALUE / IfcElectricCurrentMeasure
    NominalCurrents: A set of nominal currents in [A] for which the data of this instance is valid. At least one value shall be provided. Any value in the set shall not exceed the value of the UltimateRatedCurrent associated with the same breaker unit.
    定格電流: 定格電流[A]を少なくても1つ値をセットしなければならない。 セット内の任意の値の値を超えてはならない。 定格電流は、同じブレーカ部に関連付けられている。
    정격 전류: 정격 전류 [A]를 적어도 2 개의 값을 설정해야한다. 동일한 차단기부와 연결된 정격전류는세트 내의 임의의 값은 초과할 수 없다.
  • ICU60947
    P_SINGLEVALUE / IfcElectricCurrentMeasure
    ICU60947: The ultimate breaking capacity in [A] for an MCB tested in accordance with the IEC 60947 series.
    定格限界短絡遮断容量: IECの60947シリーズに基づいてテストされたMCBの定格限界短絡遮断容量を[A]で設定。
    정격 한계 단락 차단 용량: IEC의 60948 시리즈를 기반으로 시험한 MCB의 정격 한계 단락 차단 용량 [A]로 설정.
  • ICS60947
    P_SINGLEVALUE / IfcElectricCurrentMeasure
    ICS60947: The service breaking capacity in [A] for an MCB tested in accordance with the IEC 60947 series.
    定格使用短絡遮断容量: IECの60947シリーズに基づいてテストされたMCBの定格使用短絡遮断容量を[A]で設定。
    정격 사용 단락 차단 용량: IEC의 60947 시리즈를 기반으로 시험한 MCB의 정격 사용 단락 차단 용량 [A]로 설정.
  • ICN60898
    P_SINGLEVALUE / IfcElectricCurrentMeasure
    ICN60898: The nominal breaking capacity in [A] for an MCB tested in accordance with the IEC 60898 series.
    ICN60898: IECの60898シリーズに基づいてテストされたMCBの定格遮断容量を[A]で設定。
    ICN60898: IEC의 60898 시리즈를 기반으로 시험한 MCB의 정격 차단 용량 [A]로 설정.
  • ICS60898
    P_SINGLEVALUE / IfcElectricCurrentMeasure
    ICS60898: The service breaking capacity in [A] for an MCB tested in accordance with the IEC 60898 series.
    ICS60898: IECの60898シリーズに基づいてテストされたMCBの遮断使用容量を[A]で設定。
    ICS60898: IEC의 60898 시리즈를 기반으로 시험한 MCB 차단 사용 용량 [A]로 설정.
