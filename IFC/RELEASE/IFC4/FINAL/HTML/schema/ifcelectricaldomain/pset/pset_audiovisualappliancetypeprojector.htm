7.4.4.7 Pset_AudioVisualApplianceTypeProjector

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / PROJECTOR

An audio-visual projector is a device that projects video to a surface. HISTORY: Added in IFC4.
画面にビデオ映像を投影する装置。

buildingSMART Data Dictionary

PSD-XML

  • ProjectorType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualProjectorType: OTHER, NOTKNOWN, UNSET.
    ProjectorType: Indicates the type of projector.
    プロジェクター形式: プロジェクタの形式を示す。
    프로젝터 형식: 프로젝터의 형식을 보여준다.
  • VideoResolutionWidth
    P_SINGLEVALUE / IfcInteger
    VideoResolutionWidth: Indicates the number of horizontal pixels (the largest native video resolution width).
    水平解像度: 水平方向のピクセル数を示す。
    수평 해상도: 가로 픽셀 수를 나타낸다.
  • VideoResolutionHeight
    P_SINGLEVALUE / IfcInteger
    VideoResolutionHeight: Indicates the number of vertical pixels (the largest native video resolution height).
    垂直解像度: 垂直方向のピクセル数を示す。
    수직 해상도: 세로 픽셀 수를 나타낸다.
  • VideoResolutionMode
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    VideoResolutionMode: Indicates video resolution modes.
    解像度モード: 解像度モードを示す。
    디스플레이 모드: 모드해상도를 보여준다
  • VideoScaleMode
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    VideoScaleMode: Indicates video scaling modes.
    ビデオスケールモード: ビデオスケーリングモードを示す。
    비디오 스케일: 비디오 크기 조정모드를 나타낸다.
  • VideoCaptionMode
    P_TABLEVALUE / IfcIdentifier / IfcLabel
    VideoCaptionMode: Indicates closed captioning modes.
    ビデオキャプションモード: クローズドキャプションモードを示す。(字幕機能）
    비디오 캡쳐모드: 자막 모드를 나타낸다.(자막 기능)
