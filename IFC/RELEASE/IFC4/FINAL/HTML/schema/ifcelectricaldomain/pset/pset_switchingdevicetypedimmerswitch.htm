7.4.4.71 Pset_SwitchingDeviceTypeDimmerSwitch

PSET_TYPEDRIVENOVERRIDE / IfcSwitchingDevice / DIMMERSWITCH

A dimmer switch is a switch that adjusts electrical power through a variable position level action. HISTORY: Added in IFC4.
各レベルの動作で電力を調整するディマースイッチ。 履歴：IFC2ｘ４へ追加。
