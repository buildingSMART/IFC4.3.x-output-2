7.4.4.5 Pset_AudioVisualApplianceTypeDisplay

PSET_TYPEDRIVENOVERRIDE / IfcAudioVisualAppliance / DISPLAY

An audio-visual display is a device that renders video from a screen. HISTORY: Added in IFC4.
画面からビデオ映像を送出する機器。

buildingSMART Data Dictionary

PSD-XML

  • DisplayType
    P_ENUMERATEDVALUE / IfcLabel / PEnum_AudioVisualDisplayType: CRT, DLP, LCD, LED, PLASMA, OTHER, NOTKNOWN, UNSET.
    DisplayType: Indicates the type of display.
    画面種類: 画面の種類を示す。
    화면 유형: 화면 종류를 나타낸다
  • NominalSize
    P_SINGLEVALUE / IfcPositiveLengthMeasure

    화면 공칭 크기: 화면의 대각선 크기를 나타낸다.
  • DisplayWidth
    P_SINGLEVALUE / IfcPositiveLengthMeasure

  • DisplayHeight
    P_SINGLEVALUE / IfcPositiveLengthMeasure

  • Brightness
