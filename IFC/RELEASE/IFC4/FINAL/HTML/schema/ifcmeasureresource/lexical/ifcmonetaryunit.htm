8.11.3.8 IfcMonetaryUnit

Unité monétaire
Monetäre Einheit

IfcMonetaryUnit is a unit to define currency for money.

HISTORY  New entity in IFC2x.
IFC4 CHANGE  Type of the attribute Currency changed.

XSD Specification:

 <xs:element name="IfcMonetaryUnit" type="ifc:IfcMonetaryUnit" substitutionGroup="ifc:Entity" nillable="true"/>
 <xs:complexType name="IfcMonetaryUnit">
  <xs:complexContent>
   <xs:extension base="ifc:Entity">
    <xs:attribute name="Currency" type="ifc:IfcLabel" use="optional"/>
   </xs:extension>
  </xs:complexContent>
 </xs:complexType>

EXPRESS Specification:

ENTITY IfcMonetaryUnit;
Currency : IfcLabel;
END_ENTITY;

 EXPRESS-G diagram

Attribute Definitions:

Currency : Code or name of the currency. Permissible values are the three-letter alphabetic currency codes as per ISO 4217, for example CNY, EUR, GBP, JPY, USD.
