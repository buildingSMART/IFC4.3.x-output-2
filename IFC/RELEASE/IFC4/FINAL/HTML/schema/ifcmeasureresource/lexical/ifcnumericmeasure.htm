8.11.2.61 IfcNumericMeasure

An IfcNumericMeasure is the numeric value of a physical quantity.

Type: NUMBER

NOTE  Type adapted from numeric_measure defined in ISO 10303-41.
HISTORY  New type in IFC1.5.1.

XSD Specification:

 <xs:simpleType name="IfcNumericMeasure">
  <xs:restriction base="xs:double"/>
 </xs:simpleType>
 <xs:element name="IfcNumericMeasure-wrapper" nillable="true">
  <xs:complexType>
   <xs:simpleContent>
    <xs:extension base="ifc:IfcNumericMeasure">
     <xs:attributeGroup ref="ifc:instanceAttributes"/>
    </xs:extension>
   </xs:simpleContent>
  </xs:complexType>
 </xs:element>

EXPRESS Specification:

TYPE IfcNumericMeasure = NUMBER;
END_TYPE;
