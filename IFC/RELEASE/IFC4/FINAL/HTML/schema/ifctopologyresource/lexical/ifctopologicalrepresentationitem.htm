8.20.3.17 IfcTopologicalRepresentationItem

Item de représentation topologique
Topologische Repräsentation - Element

NOTE  Definition according to ISO/CD 10303-42:1992
The topological representation item is the supertype for all the topological representation items in the geometry resource.
NOTE  Entity adapted from topological_representation_item defined in ISO 10303-42.
HISTORY  New entity in IFC1.5

EXPRESS Specification:

ENTITY IfcTopologicalRepresentationItem
ABSTRACT SUPERTYPE OF(ONEOF(IfcConnectedFaceSet, IfcEdge, IfcFace, IfcFaceBound, IfcLoop, IfcPath, IfcVertex))
SUBTYPE OF IfcRepresentationItem;
END_ENTITY;
