7.6.4.25 Pset_WasteTerminalTypeWasteTrap

PSET_TYPEDRIVENOVERRIDE / IfcWasteTerminal / WASTETRAP

Pipe fitting, set adjacent to a sanitary terminal, that retains liquid to prevent the passage of foul air.
液体を溜めて汚れた空気の通過を防ぐよう衛生機器に隣接して設置させた配管。
