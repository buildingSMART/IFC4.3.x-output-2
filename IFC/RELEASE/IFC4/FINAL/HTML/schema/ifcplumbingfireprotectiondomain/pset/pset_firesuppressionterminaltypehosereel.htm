7.6.4.4 Pset_FireSuppressionTerminalTypeHoseReel

PSET_TYPEDRIVENOVERRIDE / IfcFireSuppressionTerminal / HOSEREEL

A supporting framework on which a hose may be wound (BS6100 155 8201). Note that the service provided by the hose (water/foam) is determined by the context of the system onto which the hose reel is connected.
ホースが損傷したときのサポートの仕組み。（BS61001558201） ホースに供給されるサービスが水か泡かは、そのホースリールが接続されているシステムによる。

    P_ENUMERATEDVALUE / IfcLabel / PEnum_HoseReelType: RACK, REEL, OTHER, NOTKNOWN, UNSET

    ホースリールタイプ: あらかじめ定義済みのホース構成の型から必要な型を設定する識別。

  • ClassOfService
