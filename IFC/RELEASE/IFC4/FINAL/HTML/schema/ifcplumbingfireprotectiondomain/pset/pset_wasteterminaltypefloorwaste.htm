7.6.4.20 Pset_WasteTerminalTypeFloorWaste

PSET_TYPEDRIVENOVERRIDE / IfcWasteTerminal / FLOORWASTE

Pipe fitting, set into the floor, that collects waste water and discharges it to a separate trap.
廃水や廃水を集めて分離する防臭弁を持つ、床に据え付けられた配管。
