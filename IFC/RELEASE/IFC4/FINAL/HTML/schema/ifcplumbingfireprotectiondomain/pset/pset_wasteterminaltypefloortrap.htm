7.6.4.19 Pset_WasteTerminalTypeFloorTrap

PSET_TYPEDRIVENOVERRIDE / IfcWasteTerminal / FLOORTRAP

Pipe fitting, set into the floor, that retains liquid to prevent the passage of foul air.
液体を溜めて汚れた空気の通過を防ぐために床に据えられる配管。
