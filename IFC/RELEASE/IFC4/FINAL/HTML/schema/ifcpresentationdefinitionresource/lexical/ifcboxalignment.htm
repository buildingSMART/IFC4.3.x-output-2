8.13.2.1 IfcBoxAlignment

The box alignment specifies the alignment of the text box relative to its position. The following string values shall be used:

  • top-left
  • top-middle
  • top-right
  • middle-left
  • center
  • middle-right
  • bottom-left
  • bottom-middle
  • bottom-right
NOTE  The top-left is the default value.
