6.5.4.8 Pset_ProjectOrderWorkOrder

PSET_TYPEDRIVENOVERRIDE / IfcProjectOrder / WORKORDER

Defines the requirements for purchase orders in a project.

buildingSMART Data Dictionary

PSD-XML

  • ProductDescription
    P_SINGLEVALUE / IfcText
    ProductDescription: A textual description of the products that require the work.
  • WorkTypeRequested
    P_SINGLEVALUE / IfcText
    WorkTypeRequested: Work type requested in circumstances where there are categorizations of types of work task. It could be used to identify a remedial task, minor work task, electrical task etc.
  • ContractualType
    P_SINGLEVALUE / IfcText
    ContractualType: The contractual type of the work.
  • IfNotAccomplished
    P_SINGLEVALUE / IfcText
    IfNotAccomplished: Comments if the job is not accomplished.
