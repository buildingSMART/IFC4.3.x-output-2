6.5.4.1 Pset_ActionRequest

PSET_TYPEDRIVENOVERRIDE / IfcActionRequest

An action request is a request for an action to fulfill a need. HISTORY: IFC4: Removed RequestSourceType, RequestDescription, Status
ファシリティマネジメントにおける施策への要請事項に関するプロパティセット定義。

buildingSMART Data Dictionary

PSD-XML

  • RequestSourceLabel
    P_SINGLEVALUE / IfcLabel
    RequestSourceLabel: A specific name or label that further qualifies the identity of a request source. In the event of an email, this may be the email address.
    要請ソースタイプ: 要請がなされる源のあらかじめ定義されたタイプの識別子。
  • RequestSourceName
    P_REFERENCEVALUE / IfcPerson
    RequestSourceName: The person making the request, where known.
    要請ソースラベル: 要請源の識別を確認するための特定の名称またはラベル。電子メールの場合、電子メールアドレスに相当する。
  • RequestComments
    P_SINGLEVALUE / IfcText
    RequestComments: Comments that may be made on the request.
    要請ソース名: 要請を作成する人物の名称。
