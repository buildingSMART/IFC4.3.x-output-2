7.3.5.1 Qto_ConstructionEquipmentResourceBaseQuantities

QTO_TYPEDRIVENOVERRIDE / IfcConstructionEquipmentResource

Base quantities that are common to the definition of all occurrences of construction equipment resources.

QTO-XML

  • UsageTime
    Q_TIME
    UsageTime: Total time using the equipment including operating time and idle time.
  • OperatingTime
    Q_TIME
    OperatingTime: Productive time using the equipment including operating time and excluding idle time.
