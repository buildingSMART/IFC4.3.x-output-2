7.3.4.1 Pset_ConstructionResource

PSET_TYPEDRIVENOVERRIDE / IfcConstructionResource

Properties for tracking resource usage over time.

buildingSMART Data Dictionary

PSD-XML

  • ScheduleWork

    ScheduleWork: The scheduled work on behalf of the resource allocation.
    予定作業時間: 資源配分のための予定された作業。
  • ActualWork
    P_REFERENCEVALUE / IfcTimeSeries / IfcDuration
    ActualWork: The actual work on behalf of the resource allocation.
    実績作業時間: 資源配分のための実績の作業。
  • RemainingWork
    P_REFERENCEVALUE / IfcTimeSeries / IfcDuration
    RemainingWork: The remaining work on behalf of the resource allocation.
    残存作業時間: 資源配分のための残存している作業。
  • ScheduleCost
    P_REFERENCEVALUE / IfcTimeSeries / IfcMonetaryMeasure
    ScheduleCost: The budgeted cost on behalf of the resource allocation.
    予定コスト: 資源配分のための予定されているコスト。
  • ActualCost
    P_REFERENCEVALUE / IfcTimeSeries / IfcMonetaryMeasure
    ActualCost: The actual cost on behalf of the resource allocation.
    実績コスト: 資源配分のための実績のコスト。
  • RemainingCost
    P_REFERENCEVALUE / IfcTimeSeries / IfcMonetaryMeasure
    RemainingCost: The remaining cost on behalf of the resource allocation.
    残存コスト: 資源配分のための残存しているコスト。
  • ScheduleCompletion
    P_REFERENCEVALUE / IfcTimeSeries / IfcNormalisedRatioMeasure
    ScheduleCompletion: The scheduled completion percentage of the allocation.
    予定完了率: 予定された完了率。
  • ActualCompletion
    P_REFERENCEVALUE / IfcTimeSeries / IfcNormalisedRatioMeasure
    ActualCompletion: The actual completion percentage of the allocation.
