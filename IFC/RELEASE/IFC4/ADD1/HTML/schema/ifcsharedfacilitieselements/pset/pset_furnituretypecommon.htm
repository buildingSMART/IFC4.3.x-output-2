6.4.4.4 Pset_FurnitureTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcFurniture

Furniture Type Common: Common properties for all types of furniture such as chair, desk, table, and file cabinet. HISTORY: First issued in IFC Release R1.5. Renamed from Pset_FurnitureCommon. IFC 2x4: 'IsBuiltIn' property added
