6.2.4.21 Pset_OutsideDesignCriteria

PSET_TYPEDRIVENOVERRIDE / IfcBuilding

Outside Design Criteria: Outside air conditions used as the basis for calculating thermal loads at peak conditions, as well as the weather data location from which these conditions were obtained. HISTORY: New property set in IFC Release 1.0.
: ピーク時熱負荷を計算するために使用する所在地の外気条件。履歴：IFC1.0に定義された新属性。
