7.4.4.39 Pset_LightFixtureTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcLightFixture

Light Fixture Type Common: Common data for light fixtures. History: IFC4 - Article number and manufacturer specific information deleted. Use Pset_ManufacturerTypeInformation. ArticleNumber instead. Load properties moved from Pset_LightFixtureTypeThermal (deleted).
: 照明器具の共通データ。 IFC4でArticleNumberは削除されました。代わりにPset_ManufacturerTypeInformationを使用してください。
