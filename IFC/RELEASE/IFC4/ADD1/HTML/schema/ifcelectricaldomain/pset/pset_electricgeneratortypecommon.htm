7.4.4.34 Pset_ElectricGeneratorTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcElectricGenerator

Electric Generator Type Common: Defines a particular type of engine that is a machine for converting mechanical energy into electrical energy.
: 機械エネルギーを電気エネルギーに変換する特殊なエンジンを定義。
