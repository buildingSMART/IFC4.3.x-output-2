7.4.4.37 Pset_JunctionBoxTypeCommon

PSET_TYPEDRIVENOVERRIDE / IfcJunctionBox

Junction Box Type Common: A junction box is an enclosure within which cables are connected. History: New in IFC4
: ジャンクションボックスは中にケーブルが接続されているケース。 IFC4にて新規。
