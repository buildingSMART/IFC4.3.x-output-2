IFCSHAREDBLDGSERVICEELEMENTS

The data model consists of the following:
32  Entities
37  Enumerations

The IfcSharedBldgServiceElements schema in the interoperability layer defines basic object concepts required for interoperability between Building Service domain extensions (notably HVAC) and other domain extensions defined in the current IFC model. This schema includes concepts such as building serive devices, flow and distribution systems focused on duct and pipe systems, and electrical properties.

HISTORY

This schema has been significantly modified in IFC R2x. Refer to the change log and issues resolution database for details.
