IfcPumpTypeEnum

Definition from IAI: Defines general types of pumps. The IfcPumpTypeEnum contains the following:

  • CIRCULATOR: Circulator.
  • ENDSUCTION: End suction.
  • SPLITCASE: Split case.
  • VERTICALINLINE: Vertical inline.
  • VERTICALTURBINE: Vertical turbine.
  • OTHER: Other type of pump.
  • NOTKNOWN: Unknown pump type.
  • UNSET: Unspecified pump type.

HISTORY: New enumeration in IFC R2x.
ISSUES: See issues and change log for changes made in IFC R2x.


EXPRESS specification:

TYPE IfcPumpTypeEnum = ENUMERATION OF
( CIRCULATOR,
ENDSUCTION,
SPLITCASE,
VERTICALINLINE,
VERTICALTURBINE,
OTHER,
NOTKNOWN,
UNSET);
END_TYPE;
