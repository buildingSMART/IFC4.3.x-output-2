IfcMoterConnectionTypeEnum

Definition from IAI: The way the motor is connected. The IfcMotorConnectionTypeEnum contains the following:

  • DIRECTDRIVE: Direct drive.
  • BELTDRIVE: Belt drive.
  • COUPLING: Coupling.
  • OTHER: Other type of motor connection.
  • NOTKNOWN: Unknown motor connection type.
  • UNSET: Unspecified motor connection type.

HISTORY: New enumeration in IFC R2x.
ISSUES: See issues and change log for changes made in IFC R2x.


EXPRESS specification:

TYPE IfcMoterConnectionTypeEnum = ENUMERATION OF
( DIRECTDRIVE,
BELTDRIVE,
COUPLING,
OTHER,
NOTKNOWN,
UNSET);
END_TYPE;
