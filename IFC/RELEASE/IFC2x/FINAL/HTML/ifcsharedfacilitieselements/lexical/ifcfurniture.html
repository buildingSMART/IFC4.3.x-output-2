IfcFurniture

Definition from IAI: An IfcFurniture is an item of furniture such as a table, desk, chair, filing cabinet etc. A furniture is a special kind of IfcFurnitureElement, which is

Any furniture might be composed of system furniture elements. In this case, the IfcRelAggregates relationship is used to aggregate one-to-many IfcSystemFurnitureElement into one IfcFurniture.

The assignment of manufacture information is done via the IfcRelDefinesByProperties relationship, which relates an instance of IfcManufactureInformation to the furniture.

HISTORY New class in IFC Release 1.0
ISSUES See issue and change log for changes made in IFC Release 2x.

Use Definitions:

The geometric representation of an IfcFurniture is given by the IfcProductDefinitionShape and IfcLocalPlacement allowing multiple geometric representations.

Local Placement

The local placement for any IfcFurniture is defined in its supertype IfcProduct. It is defined by the IfcLocalPlacement, which defines the local coordinate system that is referenced by all geometric representations.

Bounding Box Representation

Any IfcFurniture may be represented as a bounding box, which shows the maximum extend of the body within the coordinated system established by the IfcLocalPlacement. The bounding box representation is the simpliest geometric representation available. It is ensured by assigning the value 'BoundingBox' to the RepresentationType attribute of IfcShapeRepresentation.

Brep Representation

Any IfcFurniture may be represented as a single or multiple Boundary Representation elements (which are restricted to faceted Brep with or without voids). The Brep representation allows for the representation of complex element shape. It is ensured by assigning the value 'Brep' to the RepresentationType attribute of IfcShapeRepresentation. In some cases it may be useful to also expose a simple representation as a bounding box representation of the same complex shape.
