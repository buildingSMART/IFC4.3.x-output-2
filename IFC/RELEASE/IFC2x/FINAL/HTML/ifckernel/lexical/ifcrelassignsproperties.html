IfcRelAssignsProperties

Definition from IAI: This objectified relationship (IfcRelAssignsProperties) defines the relationships between properties and objects. Properties are aggregated in property sets, property sets can be grouped to define a property style. Either a property style or a single property set participates in that relationship.

The IfcRelAssignsProperties is a 1-to-N relationship, as it allows for the assignment of one property style or property set to a single or to many objects.

HISTORY New Entity in IFC Release 2.0

EXPRESS specification:

ENTITY IfcRelAssignsProperties
SUBTYPE OF ( IfcRelationship);
RelatingPropertyDefinition  :  IfcPropertyDefinition;
RelatedObjects  :  SET [1:?] OF IfcObject;
DomainView  :  OPTIONAL IfcLabel;
DERIVE
IsShared  :  LOGICAL :=  HIINDEX(RelatedObjects) > 1;
END_ENTITY;

Attribute definitions:

RelatingPropertyDefinition  :  Reference to the property definition for that object or set of objects.
RelatedObjects  :  Reference to the objects (or single object) to which the property definition applies.
DomainView  :  The attribute DomainView optionally defines the domain, to which the assigned IfcPropertyDefinition relates. If not present, the IfcPropertyDefinition is applicable to all domain views. The DomainView is interpreted by applications and has to be further defined in addtional agreements.
IsShared  :  The attribute IsShared reflects whether the property is assigned to a single object instance (FALSE = occurrence property,) or assigned to multiple object instances (TRUE = shared property, see semantic definition at IfcObject).
