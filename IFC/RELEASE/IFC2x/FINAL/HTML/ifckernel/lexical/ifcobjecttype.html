IfcObjectType

Definition from IAI: The object type (IfcObjectType) defines the specific information about a type. It refers to the specific level of the well recognized generic - specific - occurrance modeling paradigm.

The object style is represented by a list of property set definitions, where the order in the list implies a decreasing generality. The list of property sets describes the available specific information about the object type. Thereby the object type is used to define the common properties of a certain type (or style) of an object that may be applied to multiple instances of the same type. The IfcObjectType gets assigned to the individual object instances (the occurrences) via the IfcRelDefinesByType relationship.

Object types may be exchanged without being already assigned to objects. An object type may have an indication of the library (or catalogue) from which its definition originates. This association is handled by the inherited HasLibraryAssignment relationship.

HISTORY New entity in IFC Release 2x
ISSUE See issue log for changes made in IFC Release 2x. The entity has been renamed from IfcPropertyStyle within the IFC Release 2x final.

EXPRESS specification:

ENTITY IfcObjectType
SUBTYPE OF ( IfcPropertyDefinition);
Name  :  IfcLabel;
Description  :  OPTIONAL IfcText;
TypeOfClass  :  OPTIONAL IfcLabel;
HasPropertySets  :  OPTIONAL LIST [1:?] OF UNIQUE IfcPropertySetDefinition;
INVERSE
ObjectTypeOf  :  SET [0:1] OF IfcRelDefinesByType FOR RelatingType;
END_ENTITY;

Attribute definitions:

Name  :  The attributes Name defines the name of the object style. The name can be declared within the IFC specification as part of the property set agreements.
Description  :  Description about the object type.
TypeOfClass  :  The attribute optionally defines the type of Object, to which the assigned object style can relate. If not present, no instruction is given to which Object the object style is applicable.
HasPropertySets  :  List of unique property sets, which constitutes the property style.
