IfcProcess

Definition from IAI: An action taking place in building construction with the intent of acquiring, constructing, or maintaining products. Processes are placed in sequence (including overlapping for parallel tasks) in time.

HISTORY New entity in IFC Release 1.0
ISSUE See issue log for changes made in IFC Release 1.5. See issue and change log for changes made in IFC Release 2x.

EXPRESS specification:

ENTITY IfcProcess
ABSTRACT SUPERTYPE
SUBTYPE OF ( IfcObject);
Productivity  :  OPTIONAL IfcMeasureWithUnit;
INVERSE
OperatesOn  :  SET OF IfcRelAssignsToProcess FOR RelatingProcess;
IsSuccessorFrom  :  SET OF IfcRelSequence FOR RelatedProcess;
IsPredecessorTo  :  SET OF IfcRelSequence FOR RelatingProcess;
END_ENTITY;

Attribute definitions:

Productivity  :  Productivity of the process (such as m³ per hour).
OperatesOn  :  Set of Relationships to objects that are operated on by the process.
IsSuccessorFrom  :  Relative placement in time, refers to the previous processes for which this process is successor.
IsPredecessorTo  :  Relative placement in time, refers to the previous processes for which this process is predecessor.
