IfcModelingAid

Definition from IAI: An IfcModelingAid provides the general concept for constructs that support the creation of design artifact, in particular its geometric form.

Most common example of a modeling aid is the object placement, which establishes the object coordinate system in which all shape representations of that object are placed.

Another example is the provision of the design grid. The grid is part of the project information set, but not part of the artifact itself. The grid supports in addition the definition of elements' constraint location relative to the grid, but the grid is not part of the constructed building.
