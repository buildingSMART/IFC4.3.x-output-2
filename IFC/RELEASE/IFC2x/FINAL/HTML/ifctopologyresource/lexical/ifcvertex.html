IfcVertex

Definition from ISO/CD 10303-42:1992: A vertex (IfcVertex) is the topological construct corresponding to a point. It has dimensionality 0 and extent 0. The domain of a vertex, if present, is a point in m dimensional real space RM; this is represented by the vertex point (IfcVertexPoint) subtype.

NOTE Corresponding STEP entity: vertex. Please refer to ISO/IS 10303-42:1994, p. 129 for the final definition of the formal standard.

HISTORY New Entity in IFC Release 2.0

Informal proposition:

  1. The vertex has dimensionality 0. This is a fundamental property of the vertex.
  2. The extent of a vertex is defined to be zero.

EXPRESS specification:

ENTITY IfcVertex
SUBTYPE OF ( IfcTopologicalRepresentationItem);
END_ENTITY;
