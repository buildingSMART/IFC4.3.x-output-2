IfcAssignsCostModifiers

Definition from IAI: An IfcAssignsCostModifiers assigns a defined set of IfcCostModifier objects to an IfcCost object to represent changes in cost of an object due to a single set of circumstances.

HISTORY: New class in IFC Release 2x
ISSUES: See issue and change log for additions and changes made in IFC Release 2x.

EXPRESS specification:

ENTITY IfcAssignsCostModifiers;
ModifierValues  :  LIST [1:?] OF UNIQUE IfcCostModifier;
ModifiedCost  :  IfcCostValue;
END_ENTITY;

Attribute definitions:

ModifierValues  :  Modifiers which may be applied to a cost to change its value.
ModifiedCost  :  Cost to which a set of modifiers is applied.
