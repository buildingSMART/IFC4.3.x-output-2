IfcRelAdjacencyRequirement

Definition from IAI: Objectified Relationship defines requirements for the adjacency of two spaces in the architectural program. The Adjacency required is encoded as an integer value between 0 and 256, where 0 means the spaces must be immediately adjacent and 256 means that they should be as far apart as possible.

HISTORY New entity in IFC Release 1.5

EXPRESS specification:

ENTITY IfcRelAdjacencyRequirement
SUBTYPE OF ( IfcRelConnects);
RelatingSpaceProgram  :  IfcSpaceProgram;
RelatedSpaceProgram  :  IfcSpaceProgram;
AdjacencyImportanceRating  :  IfcNormalisedRatioMeasure;
END_ENTITY;

Attribute definitions:

RelatingSpaceProgram  :  Architectural program for the first Space.
RelatedSpaceProgram  :  Architectural program for the second Space.
AdjacencyImportanceRating  :  Ratio measure (between 0 and 1) for the required adjacency between these two spaces. 1 represents immediate adjacency required, 0 represents spaces should be as far apart as possible.
