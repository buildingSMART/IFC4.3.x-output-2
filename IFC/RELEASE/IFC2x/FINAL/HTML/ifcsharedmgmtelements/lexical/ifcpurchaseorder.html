IfcPurchaseOrder

Definition from IAI: An IfcPurchaseOrder defines a set of properties for purchase orders in a project.

HISTORY New Entity in IFC Release 2.0
ISSUES No issues so far.

EXPRESS specification:

ENTITY IfcPurchaseOrder
SUBTYPE OF ( IfcProjectOrder);
RequiredDate  :  OPTIONAL IfcCalendarDate;
ScheduledDate  :  OPTIONAL IfcCalendarDate;
ActualDate  :  OPTIONAL IfcCalendarDate;
IsFOB  :  OPTIONAL BOOLEAN;
ShipMethod  :  OPTIONAL IfcLabel;
PurchaseItems  :  OPTIONAL IfcCostSchedule;
TotalCost  :  OPTIONAL IfcCostValue;
Status  :  IfcPurchaseOrderStatusEnum;
END_ENTITY;

Attribute definitions:

RequiredDate  :  The required date of receiving the requested items.
ScheduledDate  :  The scheduled date of receiving the requested items.
ActualDate  :  Actual date of receiving the purchased items.
IsFOB  :  Is Free on Board?; True means 'yes'; False means 'no'.
ShipMethod  :  Method of shipping.
PurchaseItems  :  Use a cost schedule to handle the list of items with both item description and cost of each cost element in the cost schedule.
TotalCost  :  Total cost of the purchase. It is derived value from 'PurchaseItems'.
Status  :  The status of the purchase order.
