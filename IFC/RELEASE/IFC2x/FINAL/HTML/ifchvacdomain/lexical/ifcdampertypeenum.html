IfcDamperTypeEnum

Definition from IAI: This enumeration defines the different types of dampers an IfcDamper object can fulfill:

  • FIREDAMPER: Fire damper.
  • SMOKEDAMPER: Smoke damper.
  • FIRESMOKEDAMPER: Combination fire and smoke damper.
  • BACKDRAFTDAMPER: Backdraft damper.
  • CONTROLDAMPER: Control damper.
  • LOUVER: Louver.
  • USERDEFINED: User-defined damper.
  • NOTDEFINED: Undefined damper.

ISSUES No issues to date.
HISTORY New enumeration in IFC R2.


EXPRESS specification:

TYPE IfcDamperTypeEnum = ENUMERATION OF
( FIREDAMPER,
SMOKEDAMPER,
FIRESMOKEDAMPER,
BACKDRAFTDAMPER,
CONTROLDAMPER,
LOUVER,
USERDEFINED,
NOTDEFINED);
END_TYPE;
