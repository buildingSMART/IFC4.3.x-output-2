IfcDamperSizingMethodEnum

Definition from IAI: This enumeration defines the sizing methods used for an instance of IfcDamper.

Valid enumerations are:

  • NOMINAL: Nominal sizing method.
  • EXACT: Exact sizing method.
  • USERDEFINED: User-defined sizing method.
  • NOTDEFINED: Undefined sizing method.
