IfcRelAssignsMaterial

Definition from IAI: Objectified relationship between a material definition and building elements to which this material definition applies. The material definition can be:

  • A single material
  • A material list, e.g. for composite elements
  • A material layer set, for layered elements which an indication of the layering direction and individual layer thicknesses

HISTORY New entity in IFC Release 2.x
ISSUE See Issue for changes made in IFC Release 2.x.

EXPRESS specification:

ENTITY IfcRelAssignsMaterial
SUBTYPE OF ( IfcRelationship);
RelatingMaterial  :  IfcMaterialSelect;
RelatedElements  :  SET [1:?] OF IfcElement;
WHERE
WR1  :  SIZEOF(QUERY(temp <* RelatedElements | 'IFCPRODUCTEXTENSION.IFCOPENINGELEMENT' IN TYPEOF(temp))) = 0;
END_ENTITY;

Attribute definitions:

RelatingMaterial  :  Material definition (either a single material, a list of materials, or a set of material layers) assigned to the elements.
RelatedElements  :  Elements to which the material definition applies.
