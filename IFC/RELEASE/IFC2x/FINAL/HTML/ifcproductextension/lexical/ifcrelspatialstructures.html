IfcRelSpatialStructures

Definition from IAI: This objectified relationship, IfcRelSpatialStructures, is used to create any hierarchical spatial project structure within a project. A spatial project structure is characterized by assigning various levels of spatial structure elements to a strict hierarchical structure. Predefined spatial structure elements are:

  • site as IfcSite
  • building as IfcBuilding
  • storey as IfcBuildingStorey
  • space as IfcSpace

Each of the predefined spatial elements can be either a complex, i.e. an aggregation of spatial elements of the same level, or a part of of a spatial element.

EXAMPLE On the level of buildings, a "complex" denotes a building complex, and a "part" denotes a building section.

The IfcRelSpatialStructures is defines as an 1-to-many relationship, and it establishes the relationship between exactly two levels within the spatial project structure.

Informal proposition:

  1. The spatial project structure, established by the IfcRelSpatialStructures, shall be acyclic.
  2. A site should not be (directly or indirectly) associated to a building, storey or space.
  3. A building should not be (directly or indirectly) associated to a storey or space.
  4. A storey should not be (directly or indirectly) associated to a space.

HISTORY New entity in IFC Release 2.x, note: previous entity IfcRelContains has been replaced.
ISSUE See issue I-335 for changes made in IFC Release 2.x

EXPRESS specification:

ENTITY IfcRelSpatialStructures
SUBTYPE OF ( IfcRelAggregates);
RelatingStructure  :  IfcSpatialStructureElement;
RelatedStructures  :  SET [1:?] OF IfcSpatialStructureElement;
END_ENTITY;

Attribute definitions:

RelatingStructure  :  Spatial structure element at a higher level within the spatial project structure, to which the related structures are assigned to.
RelatedStructures  :  Structure elements at a lower level within the spatial project structure, which are associated to an element on a higher level.
