IfcRelAssemblesElements

Definition from IAI: Objectified Relationship that assembles various elements (or other element assemblies) into an element assembly. The Elements shall have a strong semantic and topological relationship and shall make up a new component within the AEC product.

Informal propositions:

  1. Both the parts in an assembly and also the assembly itself are of type IfcElement (or one of its subtypes).
  2. Any element can only be part of maximum one assembly relationship to form a part and of maximum one assembly relationship to form the whole.

HISTORY New entity in IFC Release 1.5
ISSUE See issue I-106 for changes made in IFC Release 1.5. See Issue GI-012 for changes made in IFC Release 1.5.1. See Issues for changes made in IFC Release 2.x

EXPRESS specification:

ENTITY IfcRelAssemblesElements
SUBTYPE OF ( IfcRelAggregates);
WHERE
WR31  :  'IFCPRODUCTEXTENSION.IFCELEMENT' IN TYPEOF(SELF\IfcRelDecomposes.RelatingObject);
WR32  :  SIZEOF(QUERY(temp <* SELF\IfcRelDecomposes.RelatedObjects | NOT('IFCPRODUCTEXTENSION.IFCELEMENT' IN TYPEOF(temp)))) = 0;
END_ENTITY;

Formal Propositions:

WR31  :  The element assembly shall only be used to define an assembly of type IfcElement.
WR32  :  Only parts of type IfcElement shall form part of an assembly.
