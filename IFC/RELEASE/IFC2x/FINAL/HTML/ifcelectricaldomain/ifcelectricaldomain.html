IFCELECTRICALDOMAIN

The data model consists of the following:
4  Entities
4  Enumerations

The IfcElectricalDomain schema in the domain layer defines basic object concepts required for interoperability between Building Service domain extensions (notably Electrical) and other domain extensions defined in the current IFC model.

HISTORY

This schema is new in the IFC R2x. Refer to the change log and issues resolution database for details.
