The IfcPresentationResource schema in the resource layer defines defines the presentation of shapes for products defined within the IFC Object Model. The presentations characterize visual properties of a product shapes, and any product can be defined by zero, one, or many of those properties. The schema defines both properties of surfaces (associated to shape aspects) and illumination conditions (by simple light sources).

NOTE: The following documents have been reviewed to provide input into the specification of the presentation resource for the IFC Object Model:

  • ISO 10303-46:1994: Industrial automation systems and integration - Product data representation and exchange Part 46: Integrated generic resources: Visual presentation
  • ISO/IEC 14772-1: 1997: The Virtual Reality Modeling Language
  • openGL 1.2 technical specification - http://www.sgi.com/software/opengl/overview.html

Please note, that for IFC 2x only very small parts of the above listed resources have been interpreted to enable the exchange of lighting models and surface material properties for VRML rendering.
