IfcAirTerminalBoxEnum

Definition from IAI: This enumeration identifies different types of air terminal boxes. Note that this enumeration does not define type-driven parameters.

Valid enumerations are:

  • VARIABLEAIRVOLUME: Variable air volume terminal box.
  • CONSTANTVOLUME: Constant volume terminal box.
  • VARIABLEAIRVOLUMEREHEAT: Variable air volume with reheat terminal box.
  • CONSTANTVOLUMEREHEAT: Constant volume with reheat terminal box.
  • VARIABLEAIRVOLUMEDUALDUCT: Variable air volume dual duct terminal box.
  • CONSTANTVOLUMEDUALDUCT: Constant volume dual duct terminal box.
  • FANPOWERED: Fan-powered terminal box.
  • USERDEFINED: User-defined terminal box.
  • NOTDEFINED: Undefined terminal box.

ISSUES The enumeration has changed in IFC R3 platform - see change log for details.
HISTORY New enumeration in IFC R2.
