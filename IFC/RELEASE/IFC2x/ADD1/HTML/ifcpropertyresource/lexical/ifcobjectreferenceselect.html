IfcObjectReferenceSelect

Definition from IAI: A select type, that holds a list of resource level entities that can be used as properties within a property set.

HISTORY: New Select Type in IFC Release 2.0, capabilities improved in IFC Release 2.x.
ISSUE: See issue and change log for changes made in IFC Release 2.x.

EXPRESS specification:

TYPE IfcObjectReferenceSelect = SELECT
( IfcMaterial,
IfcPerson,
IfcDateAndTime,
IfcMaterialList,
IfcOrganization,
IfcCalendarDate,
IfcLocalTime,
IfcPersonAndOrganization,
IfcMaterialLayer,
IfcExternalReference);
END_TYPE;
