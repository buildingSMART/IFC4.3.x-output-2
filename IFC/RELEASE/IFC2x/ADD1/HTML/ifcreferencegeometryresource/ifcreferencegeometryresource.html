IfcReferenceGeometryResource

The schema IfcReferenceGeometryResource defines different types of reference geometry, using topological and geometric representation items. There are three different types of reference geometry considered:

  • vertex, given by either IfcVertex or IfcVertexPoint
  • edge, given by either IfcEdge or IfcEdgeCurve
  • face, given by either IfcFace or IfcFaceSurface
HISTORY: New schema in IFC 2x, definitions (which had been enhanced in IFC 2x) were part of the IfcModelingAidExtension in earlier IFC Releases.
