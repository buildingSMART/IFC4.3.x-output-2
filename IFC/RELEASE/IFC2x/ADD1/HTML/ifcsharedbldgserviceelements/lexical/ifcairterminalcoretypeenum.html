IfcAirTerminalCoreTypeEnum

Definition from IAI: Enumeration that identifies the way the core of the AirTerminal is constructed. The IfcAirTerminalCoreTypeEnum contains the following:

  • SHUTTERBLADE: The AirTerminal has a shutter-blade core.
  • CURVEDBLADE: The AirTerminal has a curved-blade core.
  • REMOVABLE: The AirTerminal has a removable core.
  • REVERSIBLE: The AirTerminal has a reversible core.
  • NONE: The AirTerminal has no core.
  • OTHER: Other type of core not defined above.
  • USERDEFINED: User-defined core type.
  • NOTDEFINED: Undefined core type.

HISTORY: New enumeration in IFC R2x.
ISSUES: See issues and change log for changes made in IFC R2x.
