IfcPoint

Definition from ISO/CD 10303-42:1992: An point (IfcPoint) is a location in some real Cartesian coordinate space Rm, for m = 1, 2 or 3.

NOTE Corresponding STEP entity: point. Only the subtype cartesian_point has been incorporated as IfcCartesianPoint. Please refer to ISO/IS 10303-42:1994, p. 22 for the final definition of the formal standard.

HISTORY New class in IFC Release 1.5
ISSUE: See issue log for changes made in IFC Release 1.5.
