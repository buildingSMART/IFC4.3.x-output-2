IfcRequirementOrCriteriaEnum

Definition from IAI: This enumeration defines whether the thermal use case is a requirement for a particular thermal space quality or a criteria. The IfcRequirementOrCriteriaEnum contains the following:

  • REQUIREMENT: Required, or desired (e.g., a local code requirement).
  • CRITERIA: Criteria, or actual value (e.g., calculated or estimated).
  • NOTDEFINED: It is not known if it is a requirement or a criteria.

HISTORY: New enumeration in IFC R2.0.
ISSUES: See issues and change log for changes made in IFC R2x.

EXPRESS specification:

TYPE IfcRequirementOrCriteriaEnum = ENUMERATION OF
( REQUIREMENT,
CRITERIA,
NOTDEFINED);
END_TYPE;
