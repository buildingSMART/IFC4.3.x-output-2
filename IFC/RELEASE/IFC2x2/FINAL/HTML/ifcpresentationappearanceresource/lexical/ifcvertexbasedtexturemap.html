IfcVertexBasedTextureMap

Definition from IAI: An IfcVertexBasedTextureMap provides the mapping of the 2-dimensional texture coordinates (S, T) to the vertices of a single surface onto which it is mapped. The surface is references through its polyloop boundary (IfcPolyLoop) - the reference is given by VertexBasedGeometry. For each vertex (IfcCartesianPoint) of the polyloop, a set of 2 (S, T) texture coordinates are given.

HISTORY: New class in IFC Release 2x Edition 2.

Informal propositions:

  1. The list of texture vertices shall correspond to the list of polygon at the referenced polyloop.
  2. The references polyloop shall be part of the vertex based geometry to which the surface style with textures is assigned.

EXPRESS specification:

ENTITY IfcVertexBasedTextureMap;
TextureVertices  :  LIST [1:?] OF IfcTextureVertex;
VertexBasedGeometry  :  IfcPolyLoop;
END_ENTITY;

Attribute definitions:

TextureVertices  :  List of texture vertex coordinates, each texture vertex refers to the Cartesian point within the polyloop (corresponding lists). The first coordinate[1] is the S, the second coordinate[2] is the T parameter value.
VertexBasedGeometry  :  Reference to a polyloop defining a face bound of a face within a vertex based geometry.
