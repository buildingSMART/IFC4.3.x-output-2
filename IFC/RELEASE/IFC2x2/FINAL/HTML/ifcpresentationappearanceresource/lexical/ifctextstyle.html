IfcTextStyle

Definition from ISO/CD 10303-46:1992: The text style is a presentation style for annotation text..

NOTE Corresponding STEP name: text_style. Please refer to ISO/IS 10303-46:1994 for the final definition of the formal standard. In order to avoid ANDOR subtype relationships, the IfcTextStyleSelect has been introduced that allows the combination of a text style as being mirrored, and/or having box characteristic, and/or having spacing, or having none of those additional properties.

HISTORY New entity in Release IFC2x 2nd Edition.

EXPRESS specification:

ENTITY IfcTextStyle;
Name  :  IfcLabel;
CharacterGlyphAppearance  :  OPTIONAL IfcCharacterStyleSelect;
TextStyles  :  OPTIONAL SET [1:3] OF IfcTextStyleSelect;
WHERE
WR11  :  HIINDEX(TextStyles) <= 3;
WR12  :  NOT(EXISTS(SELF.TextStyles)) OR (SIZEOF(QUERY(Style1 <* SELF.TextStyles | SIZEOF(QUERY(Style2 <* SELF.TextStyles - Style1 | TYPEOF(Style1) = TYPEOF(Style2) )) > 0 )) = 0 );
END_ENTITY;

Attribute definitions:

Name  :  Name of the text style.
CharacterGlyphAppearance  :  A character style to be used for presented text.
TextStyles  :  The style(s) applied to the text for its visual appearance.

Formal Propositions:

WR11  :  The shall be a maximum of 3 different text styles assigned.
WR12  :  All of the text styles shall be of different type.
