IfcStructuralMember

Definition from IAI: The abstract entity IfcStructuralMember is the superclass of all structural elements representing the structural behaviour of building elements. A further differentiation is made for structural curve members and structural face members (see IfcStructuralCurveMember and IfcStructuralFaceMember).

NOTE: Currently only the subtypes IfcStructuralCurveMember and IfcStructuralFaceMember are defined. However, for dynamic calculations, an extension for 'point members' will be necessary and might be added in future releases.

HISTORY: New entity in Release IFC2x Edition 2.

Use Definition

Assignment of Material
The relationship to a specific material definition is provided by the entity class IfcRelAssociatesMaterial. The instance of IfcStructuralMember is used to represent collectively its subclasses IfcStructuralCurveMember and IfcStructuralFaceMember.

 Illustration of material definition

Assignment of Profile Properties
The example below illustrates the definition of profile (cross section) properties with the help of the relationship class IfcRelAssociatesProfileProperties. The latter can be used more than once to enable the specification of different profile properties at selected points along the axis of the respective structural member. When this option is used, it must additionally be ensured that the location / orientation of the separate cross sections is provided by using the same topological elements (IfcVertexPoint) as in the topological representation of the structural member.

EXPRESS specification:

ENTITY IfcStructuralMember
ABSTRACT SUPERTYPE OF (ONEOF(IfcStructuralCurveMember, IfcStructuralSurfaceMember))
SUBTYPE OF ( IfcStructuralItem);
INVERSE
ConnectedBy  :  SET OF IfcRelConnectsStructuralMember FOR RelatingStructuralMember;
END_ENTITY;

Attribute definitions:

ConnectedBy  :  Inverse relationship to all structural connections (i.e. to supports or connecting elements) which are defined for this structural member.
