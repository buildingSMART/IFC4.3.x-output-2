IfcStructuralPointConnection

Definition from IAI: Instances of the entity IfcStructuralPointConnection shall be used to describe structural nodes or point supports. All values defined by AppliedCondition are given within the local coordinate system, which is defined by this instance.

HISTORY: New entity in Release IFC2x Edition 2.

EXPRESS specification:

SUBTYPE OF ( IfcStructuralConnection);
END_ENTITY;
