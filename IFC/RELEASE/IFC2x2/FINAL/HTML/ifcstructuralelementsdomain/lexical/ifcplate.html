IfcPlate

Definition from IAI: A plate (IfcPlate) is a flat part with constant thickness, normally made of steel or other metallic material. Although not necessarily, plates are often add-on parts. This is represented by the IfcRelAggregates decomposition mechanism.

An instance IfcPlate should preferably get its geometric representation and material assignment throught the type definition by IfcPlateType assigned using the IfcRelDefinesByType relationship. This allows identical plates in a construction to be represented by the same instance of IfcPlateType.

HISTORY New entity in IFC Release 2x2

Use definition for steel members

When using the IfcPlate for steel members in steel construction applications the following additional conventions apply:

Definition by non-geometric properties:
Additional non-geometric properties can be specified through the class IfcPropertySet, which is attached to the inverse attribute IfcObject.IsDefinedBy through the objectified relationship IfcRelDefinesByProperties. This allows for attaching country-specific information to structural members.

Decomposition:
An instance of IfcPlate can be part of a decomposition through the IfcRelAggregates relationship - both as sub-ordinate or as a super-ordinate component.

  • If the IfcPlate instance is a sub-ordinate component (i.e. the plate is an add-on part), its local placement shall be relative to that of the super-ordinate instance.
  • As a super-ordinate component, the sub-ordinates of IfcPlate can be other plates or instances of IfcProxy, or IfcDiscreteAccessory (like IfcFastener).

Position number:
The position number is assigned through the attribute IfcElement.Tag

Geometry use definition

Assignment of parts to be mapped:
The IfcPlate shall not have its own geometric representation. The block mechanism is always used instead: The attribute Representation' references an IfcMappedItem (via IfcProductRepresentation and IfcRepresentation). It maps the type definition represented by IfcPlateType, which contains the geometric representation, its material assignment and other, non geometric properties. A single instance of IfcPlateType can have many occurrences. The IfcCartesianTransformationOperator, which is referenced by the IfcMappedItem, shall neither mirror the block definition, nor change its scale. Furthermore, only rotations among the plates longitudinal axis are allowed.

Local Placement:
The above mentioned IfcMappedItem is located relative to the IfcLocalPlacement referenced by the attribute ObjectPlacement. This placement itself can be relative to the world co-ordinate system or, depending on the placement objects attribute PlacementRelTo, relative to another objects co-ordinate system. If the actual IfcPlate is a subordinate in an aggregation relationship, it must be placed relative to the super-ordinate instance. Additionally, the IfcPlate can be explicitly translated in all directions and rotated among its longitudinal axis by the IfcCartesianTransformationOperator3D which is applied by the IfcMappedItem.
