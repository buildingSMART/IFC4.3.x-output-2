IFCPRODUCTEXTENSION

The data model consists of the following:

44  Entities
7  Enumerations

The IfcProductExtension defines the subtypes (3rd level of the inheritance hierarchy) of IfcProduct, which is provided within the IfcKernel. Basis concepts, introduced within the IfcProductExtension, are:

  • the spatial project structure
  • the element
  • the grid

The spatial project structure defines the site, the building, the building storey and the space and its decomposition structure. An element is assigned to the spatial project structure and may refer to a grid. Basic types of elements, which are introduced are

  • building element
  • opening element
  • electrical element
  • furnishing element
  • distribution element
  • transportation element
  • equipment element

Additionally the concepts of system and zone are introduced within the IfcProductExtension.
