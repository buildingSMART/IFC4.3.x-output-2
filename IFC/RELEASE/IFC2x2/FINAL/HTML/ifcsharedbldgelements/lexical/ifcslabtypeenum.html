IfcSlabTypeEnum

Definition from IAI: This enumeration defines the available predefined types of a slab. A special property set definition may be provided for each predefined type.

HISTORY New type in IFC Release 2.0

Floor The slab is used to represent a floor slab.
Roof The slab is used to represent a roof slab (either flat or sloped).
Landing The slab is used to represent a landing within a stair or ramp.

EXPRESS specification:

TYPE IfcSlabTypeEnum = ENUMERATION OF
( FLOOR,
ROOF,
LANDING,
USERDEFINED,
NOTDEFINED);
END_TYPE;
