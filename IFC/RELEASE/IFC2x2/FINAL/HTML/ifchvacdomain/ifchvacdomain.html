IFCHVACDOMAIN

The data model consists of the following:

31  Entities

The IfcHvacDomain schema in the domain layer defines basic object concepts required for interoperability within the heating, ventilating and air conditioning (HVAC) domain.

HISTORY

This schema has been significantly modified in IFC R2x2. Refer to the change log and issues resolution database for details.
