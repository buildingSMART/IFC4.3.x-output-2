IfcPreDefinedTextFont

Definition from IAI: The pre defined text font determines those qualified names which can be used for fonts that are in scope of the current data exchange specification (in contrary to externally defined text fonts).

NOTE: Corresponding STEP name: pre_defined_text_font. Please refer to ISO/IS 10303-46:1994, p. 138 for the final definition of the formal standard.
HISTORY: New entity in Release IFC2x Edition 2.
