IfcCircleHollowProfileDef

Definition from IAI: The IfcCircleHollowProfileDef defines a section profile that provides the defining parameters of a circular hollow section (tube) to be used by the swept surface geometry or the swept area solid. Its parameters are according to the following illustration.The centre of the position coordinate system is in the profiles centre of gravity. The profile is therefore centred in the position coordinate system.

HISTORY: New entity in Release IFC2x Edition 2.

Illustration:


Figure: Parameters of circular hollow profile definition

EXPRESS specification:

ENTITY IfcCircleHollowProfileDef
SUBTYPE OF ( IfcCircleProfileDef);
WallThickness  :  IfcPositiveLengthMeasure;
WHERE
WR1  :  WallThickness < SELF\IfcCircleProfileDef.Radius;
END_ENTITY;

Attribute definitions:

WallThickness  :  Thickness of the material, it is the difference between the outer and inner radius.

Formal Propositions:

WR1  :  Th wall thickness shall be smaller then the radius.
